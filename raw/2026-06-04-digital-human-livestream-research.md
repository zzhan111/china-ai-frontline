## 一、AI 教程主播调研：谁在卖、卖什么、怎么卖

### 1.1 标杆案例

#### 李一舟（行业天花板）

- **人设**：「清华博士」
- **主阵地**：抖音 → 被封后转战视频号
- **核心产品**：《每个人的人工智能课》，定价 199 元（标价 999 元）
- **数据**：年销 25 万份，年营收约 5000 万元
- **直播形式**：录播循环 + 真人偶尔出镜
- **被封原因**：争议性营销 + 学历质疑
- **复活路径**：转战视频号，99 元课程重新上线
- **来源**：虎嗅、36氪、华尔街见闻等多源交叉验证

#### OpenClaw 龙虾课生态（2026 年最新爆发赛道）

- **来源**：证券时报调查报道

- **主力购买群体**：**全职妈妈**
- **生态构成**：
  - 淘宝：代部署 OpenClaw 服务
  - YouTube：「养虾大法」免费教程引流

- **用户观察到的案例**：1500 元/课 + 1000+ 人同时在线，完全符合当前市场热度


### 2.3 数字人行业格局

> 来源：钛媒体「硅基研究室」2025 年行业深度分析

#### 行业周期

- **2024 年**：借大模型「重生」，多家厂商获新一轮融资，代理江湖扩张
- **2025 年**：进入洗牌期。企业从「能不能用」走向「有没有用」
  - 咨询客户「有备而来」，直接比价、问 ROI
  - 数字人无法全能的共识形成
  - 企业意识到数字人只能协同 + 降本，不能替代人

#### 三类玩家

| 类型 | 代表 | 定位 |
|------|------|------|
| 大厂派 | 腾讯智影、百度曦灵、京东言犀、商汤如影、华为 MetaStudio | 入口价值 + 串联云端算力/MaaS/AIGC |
| 垂直派 | 硅基智能、风平智能、小冰、魔珐科技、出门问问、中科深智 | 产品矩阵 + 渠道资源 |
| AI 派 | 零一万物、阶跃星辰、智谱 AI | 大模型创企，数字人在射程内 |

#### 三线并进降门槛

1. **降价**：源码厂商价格卷到几千元（「几乎是白菜价」），但鱼龙混杂（套壳多）
2. **开源**：heygem.ai（硅基）、EchoMimic V2（阿里）、Sonic（腾讯+浙大）、JoyHallo（京东）、Latentsync（字节）
3. **产品化**：从项目制 → 产品制，大厂提供标准化方案 + 数字人组件商店

#### 市场数据

- 天眼查：截至 2024 年，中国数字人相关企业 **114.4 万家**
- 2024 年前 5 个月新增注册 17.4 万余家
- 竞争极度激烈，「鱼多人多」是行业共识

### 2.4 企业应用数字人的三种打法

| 打法 | 场景 | 适用 |
|------|------|------|
| 创新直播样态 | 总裁 IP / 双数字人直播，头部品牌店播新玩法 | 大品牌 |
| 矩阵直播（闲时补充） | 数字人 + 真人主播协同，覆盖全时段 | 中型商家 |
| 强运营模式（量大管饱） | 数字人源码 + 矩阵直播 + 私域裂变 | 中小企业（需强操盘能力） |

### 2.5 平台合规政策

| 平台 | 政策 | 风险等级 |
|------|------|---------|
| **抖音** | ⛔ 明确禁止无人直播。数字人必须配合真人互动或标注 AI 生成 | 高 |
| **快手** | ⚠️ 允许但需标注，无流量扶持 | 中 |
| **视频号** | ✅ 相对宽松，标注即可 | 低 |
| **淘宝** | 允许数字人直播，需标注 | 低-中 |

**关键提醒**：平台规则频繁变动，开播前以最新政策为准。建议先跑通视频号再扩平台。

## 三、数字人直播工作流设计（面向 AI 教程卖课）

### 准备阶段（开播前 3 天）

```
├─ 脚本准备
│   ├─ AI 生成直播话术
│   ├─ 产品介绍 + 定价说明
│   ├─ 常见 QA 预置（20-30 条）
│   └─ 逼单话术模板
│
├─ 数字人制作
│   ├─ 选平台：推荐硅基智能 DUIX 3.0（¥399/月）
│   ├─ 形象克隆：5 张照片 + 2 分钟音频
│   ├─ 声音克隆或选择 TTS
│   └─ 测试视频：生成 1 段 3 分钟 demo，检查口型+自然度
│
├─ 课件准备
│   ├─ PPT / 屏幕录制演示素材
│   ├─ 安装步骤截图（关键步骤分屏展示）
│   └─ 价格牌 / 二维码贴片
│
└─ 直播间搭建
    ├─ OBS 场景配置
    ├─ 数字人推流接入
    ├─ 直播间背景图 + 贴片
    └─ 弹幕关键词触发规则配置
```

### 开播阶段

```
├─ OBS 推流 → 视频号/快手
├─ 数字人主讲述（录播循环，每段 5-8 分钟）
├─ 屏幕共享：实际演示安装过程
├─ AI 弹幕回复：
│   ├─ 关键词触发：「价格」「怎么买」「适合我吗」→ 自动回复
│   ├─ 引导加微信 / 点击购物车
│   └─ 复杂问题标记 → 下播后人工回复
└─ 真人盯盘：
    ├─ 逼单节点（最后 10 分钟）切真人
    ├─ 高客单价咨询（¥299+）切真人
    └─ 突发情况处理
```

### 下播后

```
├─ 数据复盘：观看人数 / 平均停留时长 / 转化率 / 加微信数
├─ A/B 测试：不同话术 / 不同时段 / 不同定价
└─ 迭代：下次优化脚本 + 调整定价策略
```
