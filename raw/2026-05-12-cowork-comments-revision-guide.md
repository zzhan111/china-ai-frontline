## 逐条处理指南

### R30：开篇钩子（保留，但重写）

**原 comment 问题**：IFC 改为 Grainger 正确；但学校史铺陈、公众号过渡要隐身

**新方向**：
> 开篇保留私人场景钩子，但将 IFC 改为 Grainger，增强 UIUC 识别度。学校背景不要展开成校史介绍，也不要列举名人；只需要让"香槟、玉米地、Grainger、工程训练"这些气味自然浮现。公众号复更和作者身份不在正文里明说，只沉淀在语气、细节和链接里。

**与宪法对应**：宪法第一章（母题）+ 第五章（红线）

---

### R44：黄晓煌/群核（保留，但重写）

**原 comment 问题**：不能把第一个人彻底改成黄晓煌原型，那会抢走七个普通人的主位置

**新方向**：
> 不直接将第一个人物改为现实创业者原型。保留"云渲染 / 工程创业 / AI 时代 GPU 集群"这条公开材料线，但将其处理为隐性 A 层珠玉镜像：不写真名，不写内心独白，不独立成节，只在普通人物的视角中被看见。它的功能是形成参照，而不是抢走主角位置。

**与宪法对应**：宪法第四章 a（双层结构）+ 第五章（红线）

---

### R52：李一帆/禾赛（保留，但重写）

**原 comment 问题**：价值很高，但不能变成"第二个人就是李一帆"

**新方向**：
> 禾赛 / 激光雷达 / 新能源车普及这条线保留为重要参照，但不直接替换第二个人物。它应作为"珠玉在前"的隐性案例出现：一个从 UIUC 出发、在硬件产业链和时代窗口中走通的前辈路径。普通人物可以在这个镜像下产生追逐、犹豫或自我怀疑，而不是简单复述成功史。

**与宪法对应**：宪法第四章 a（双层结构）

### R81：留美大厂画像（重点保留，并重写）

⭐️ **这是核心 comments 之一**

**原 comment 问题**："编程能力几乎完全被 Coding Agent 替代"说得太重，会显得失真

**新方向**：
> 没回的前两个普通人物要从 Anthropic 式顶尖研究员画像，改成更贴近老读者的大厂工程师画像：UIUC 工程背景，进入 Amazon / Meta / Apple 等大厂，拿 H1B，排 EB2，原本以为路径清晰。但这几年他们开始感到不安：学校和工作中长期训练出的编程、工具、协作能力仍然重要，却正在被新的生产力工具重新定价。留下不是因为完全从容，而是身份、收入、家庭、路径惯性共同把他们按在原地。

**与宪法对应**：宪法第一章（母题——"路线被改写"） + 第二章承诺二三（AI 是症状不是病因、所学没被淘汰只是定价改变）+ 第四章（没有人真的从容）

**新方向**：

## 初稿改写的优先级顺序

当后续开始改写初稿时，comments 的应用优先级应为：

```
先普通人，后珠玉
先不安，后成功
先细节，后时代
```

**核心**：R81 和 R94（两个关键普通人物的方向）  
**支撑**：R44、R52（珠玉镜像的材料约束）  
**结构**：R30、R117（开篇和收尾的硬约束）  
**放弃**：R62（不进入 001）
