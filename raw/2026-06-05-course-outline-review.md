# 课程大纲 Review — 数字人直播卖 AI 教程

Review 对象：模块 1-3 课程大纲（¥99 → ¥299 → ¥499）
Review 标准：横向对比市场上已有竞品（李一舟、OpenClaw 龙虾课、张诗童等），按"学员付费决策链条"审查

---

## 1. 整体结构评价

**✅ 好的地方**：
- 三级递进定价清晰（引流 → 利润 → 高客单）
- 每个课时都有"实战产出"而非纯理论（"安装成功的 agent"、"跑通的 MCP"比"什么是 AI agent"有价值）
- 模块 1 确实能"手把手带你配"（与 OpenClaw 龙虾课的 USP 对齐）
- 模块 3 的"自媒体内容管线"和"变现路径"击中创作者痛点

**⚠️ 需要调整的地方**：

### 问题 A：模块 1 定价 ¥99 有误导——要么是赔钱赚吆喝，要么是噱头

对比竞品：
- 李一舟 199 元年销 25 万份
- OpenClaw 龙虾课从 39.8 到 18999，**中间层的"实操训练营"卖到 300-1500**

¥99 作为**引流课**定价太低——"全家桶安装" 4 个课时（80 分钟录播 + 每个产出真实可验证结果）的价值**远超 99 元**。

**建议**：
- 保持"引流课"定位，但价格提到 **¥199**（与李一舟同一档，验证过市场）
- 或者做成"限时特价 ¥99 → 今晚 12 点恢复 ¥199"——数字人直播的锚定 + 紧迫感策略
- 如果坚持 ¥99，就需要**取消录播形式**改成"免费直播（引流到私域），加微信后再收模块 2"

### 问题 B：模块 2 缺少"中间逼单节点"

学员模块 1 学完（agent 装好了、跑通了），模块 2 差一个**转化节点**——"你现在学到这步，接下来用一个真实项目来练手"。调研报告里提到李一舟的转化话术："这个工具你现在学会了——接下来我用它帮你做一个能赚钱的项目"。

**建议**：模块 2 课时 1 开始时加一个 5 分钟**预热模板**（"你已经在模块 1 装好了 agent——现在用这个 agent 自己做一个能赚钱的东西"）。

### 问题 C：模块 3 混了两个不同受众——需要分拆或取舍

课程模块 3 包含"自媒体"和"数字人直播"两条线——但**学员可能只想学其一**：
- 想做自媒体的要"内容管线"（1-2 课时）
- 想做数字人直播的要"硅基智能注册 + 数字人生成"（3-4 课时）
- 两条线的技术栈完全不同（Hermes agent 编排 vs 硅基智能 DUIX API）

模块 3 总共 4 课时，每边分了 2-3 课时**不够深入**——学完"自媒体内容管线"的学员会问"怎么批量生产内容、怎么做数据分析"，学完"数字人直播"的学员会问"怎么优化口型、怎么联动 Agent——没有一个回答得了。

**建议**：
- 拆成**模块 3（自媒体自动化）¥499** + **模块 4（数字人直播入门）¥799**
- 或者保持 3 模块，模块 3 只讲**一条线**（比如"自媒体自动化"），"数字人直播"作为**额外加购模块**

### 问题 D：模块 1 课时 3 的"OBS + 桌面美化"定位模糊

"OBS 推流"是**直播工具**，不是"安装 agent"的技能——学员学 AI 安装的，突然跳到 OBS 会困惑。

**建议**：
- 把 OBS 相关的移到模块 4（数字人直播操作）
- 模块 1 课时 3 改成"**OpenClaw 插件开发入门**"（调 Github API、写第一个简单 skill）——延续"从安装到实战"的学习曲线
- 或者换成"**Hermes 配置最佳实践**"（配置文件、Gateway、MCP 桥接）——更顺

## 2. 学习体验审查

### 学员学习路径分析

一个学员买模块 1 后，**需要多久才能自己跑通一个 agent？**

按目前大纲：
- 课时 1-4：80 分钟录播 + 每个课时至少 20 分钟动手实验 = **≈4 小时**
- 学员是技术基础低的宝妈/个体户/白领，4 小时太长了

**竞品对比**：
- OpenClaw 龙虾课的"3 天实操直播课"结构——每天 1.5 小时，分 3 天
- 张诗童的 3 天起号课程——第一天就见到成果的"快感"

**建议**：
- 不是 4 课时录播，是**3 天直播**串讲：
  - Day 1：安装 + 验证（2 小时，产出：agent 在跑）
  - Day 2：配置 + 第一个 MCP 工具（2 小时，产出：agent 做了一个搜索任务）
  - Day 3：桌面配置 + 工作流搭建（2 小时，产出：agent 连上自己的工作流）
- 或者**录播 + 每天 30 分钟 QA 直播**（把 80 分钟拆成 30+30+20，中间插 QA）

### 学员的可证性（能不能让学员"看到自己做到了"）

这个问题是转化率的核心——OpenClaw 龙虾课能卖 18999 的关键是**"3 天后你自己能部署一个 AI agent"** 而不是 "3 天课听完后你知道了 AI 是什么"。

按目前大纲，可证性点：
- 课时 1：启动 OpenClaw 成功 ✅
- 课时 2：Hermes agent 在跑 ✅
- 课时 3：OBS + 桌面配好（转换不自然 ❌）
- 课时 4：agent 跑通工作流 ✅

建议统一可证性：每个课时最后的 5 分钟是"**打卡模板**"——学员贴出自己 agent 运行的截图 = "我做到了"。直播课里真人可以在评论区贴图。

## 4. 竞品差异化审查

| 维度 | 李一舟 | OpenClaw 龙虾课 | 本课程 |
|---|---|---|---|
| 人设 | "清华博士"（争议） | 网赚 community（非个人 IP） | "新手友好 + 真实经验 + **零技术门槛**" |
| 内容深度 | AI 扫盲 | AI Agent 安装（单一产品） | **全家桶 + 真实工作流** |
| 变现路径 | 卖课 → 私域 | 引流 → 代部署 | **卖课 → 技能资产（学员获得永久可复用能力）** |
| 差异化优势 | 品牌曝光 | 市场爆发期 | **跨平台工具覆盖 + 零技术门槛的保证** |

**结论**：差异化在"跨工具全覆盖"（OpenClaw + Hermes + Visnex）和"学员获得的是技能资产而非一次性服务"——这个点在模块 1 的 intro 里**明确强调**：

> "学完这课，你获得的不只是一个 AI 安装方法——你获得的是一个**技能资产**。以后你看到新的 AI 工具，自己就能配。"

## 6. 最终判断

**大纲方向对**（"技能资产"差异化 + 0 技术门槛 + 跨平台覆盖），但**需要 5 处调整**后再写话术脚本——不然直播时 QA 来问"模块 1 为什么学 OBS"、"模块 3 为什么同时教自媒体和数字人"会打断节奏。

**优先级排序**：
1. 🔴 **拆模块 3**：自媒体和数字人各成独立模块
2. 🔴 **定价 ¥99 → ¥199**：换课时 3 内容后重新定价
3. 🟡 **模块 1 课时 3 改内容**：OBS 换成 agent 配置
4. 🟡 **模块 2 加转化锚点**：5 分钟"预热模板"
5. 🟡 **学习路径改成 3 天直播**
