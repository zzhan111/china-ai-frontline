基于 v1 Review 的 5 处修改，重构为 4 模块递进结构。

## 模块 1: AI Agent 全家桶安装（¥199 引流课 | 3 天录播 + 每天 30 分钟 QA 直播）

> "3 天后，你自己能部署一个 AI agent——不是看完课才知道 AI 是什么。"

### Day 1（约 2 小时）
**课时 1: OpenClaw 龙虾安装与初次配置（30 分钟录播 + 20 分钟动手）**
- 下载 → 安装 → 环境变量 → 验证运行
- 产出：`openclaw --version` 成功输出 + 截图打卡

**课时 2: 你的第一个 AI 工具链：OpenClaw + Claude API 对接（30 分钟录播 + 20 分钟动手）**
- 配 API key → 第一次对话测试 → 第一个简单搜索任务
- 产出：agent 完成一次"帮我搜索 xxx"任务 + 截图打卡

### Day 2（约 2 小时）
**课时 3: Hermes Agent 搭建（30 分钟录播 + 20 分钟动手）**
- CLI 安装 → 配置文件 → 启动 Gateway → 第一个 MCP 工具
- 产出：`hermes gateway run` 成功运行 + `/api/overview` 返回 HTTP 200 + 截图打卡

**课时 4: 多 agent 串联——OpenClaw 调 Hermes skill（30 分钟录播 + 20 分钟动手）**
- 配置 `.mcp.json` → Hermes 暴露工具 → OpenClaw 订阅并调用
- 产出：OpenClaw 调成功一次 Hermes skill（如本地文件操作）+ 截图打卡

### Day 3（约 2 小时）
**课时 5: 工作流搭建——从搜索到文件写的完整 pipeline（40 分钟录播 + 30 分钟动手）**
- 搜索 → 推理 → 写文件 → 验证文件存在
- 产出：agent 完成一次"搜索 xxx → 总结 → 写入 inbox" 完整链路 + 截图打卡

**课时 6: 复盘 + 中阶预告（20 分钟直播，真人出镜）**
- 串讲模块 1 全部产出 → 展示"技能资产"概念 → 预告模块 2 的"真实赚钱项目"

## 模块 2: 工作流提效实战（¥299 | 3 天录播 + 每天 30 分钟 QA 直播）

> "模块 1 你装好了 agent。模块 2 用你做的一个真实赚钱项目来练手。"

### 预热（Day 1 开场 5 分钟，录播）
🎯 转化锚点：展示一个**真实赚钱案例**——"上周有个学员用这套 agent 工作流，一天自动生成 5 篇公众号文章，每篇 0.5 小时成本降为 0。他现在的自媒体副业月入 ¥3000。"

### Day 1（约 2 小时）
**课时 1: MCP 协议深度实战——coze-mcp-server 对接（30 分钟录播 + 20 分钟动手）**
- `.mcp.json` 配置 → `user_env` 安全模式 → SAT token 加载
- 产出：`get_me` 返回真实 Coze 账号信息 + 截图打卡

**课时 2: Coze bot 创建 + 调用——第一个云端 LLM 对话（30 分钟录播 + 20 分钟动手）**
- `create_bot` → `publish_bot` → `chat_with_bot` 全链路
- 产出：bot 真实回复结果 + 截图打卡

### Day 2（约 2 小时）
**课时 3: 知识库 + RAG 搭建（40 分钟录播 + 30 分钟动手）**
- 本地文档索引 → 向量化 → query 式知识检索 → 接入 agent 上下文
- 产出：agent 回答"根据我的知识库，xxx 是什么"能引用原文 + 截图打卡

**课时 4: 多 agent 协作——task_delegate 实战（30 分钟录播 + 20 分钟动手）**
- task_delegate 分发 → 异步子任务 → 结果合并
- 产出：3 个子代理并行完成 3 个搜索任务 + 结果合并成 1 份报告 + 截图打卡

### Day 3（约 2 小时）
**课时 5: 完整工作流——从 Coze bot 到本地文件的端到端（40 分钟录播 + 30 分钟动手）**
- 用户 query → agent 决策 → MCP 调 Coze bot → 结果写文件 → commit → push
- 产出：一个真实的 commit（如 `inbox/2026-06.md` 新增条目）+ 截图打卡

**课时 6: 复盘 + 副业预告（20 分钟直播，真人出镜）**
- 串讲模块 2 全部产出 → 预告模块 3 "自媒体自动化"和模块 4 "数字人直播"

## 模块 3: 自媒体内容自动化（¥499 | 2 天录播 + 每天 30 分钟 QA 直播）

> "学完模块 2 你会调 agent 了。模块 3 用 agent 帮你做一件能赚钱的事——自动发帖。"

### Day 1（约 2 小时）
**课时 1: inbox → posts 内容管线搭建（40 分钟录播 + 30 分钟动手）**
- 原始想法 → inbox 追加 → agent 消费 → 生成 posts/ 草稿
- 产出：一个真实的 `posts/` 草稿（含标题 + 正文 + 标签）+ 截图打卡

**课时 2: X / 小红书 / 朋友圈三平台自动分发（40 分钟录播 + 30 分钟动手）**
- 一条内容 → 三平台格式适配（X thread → 小红书笔记 → 朋友圈短文）
- 产出：一条内容生成三平台草稿 + 截图打卡

### Day 2（约 2 小时）
**课时 3: 批量生产——一天 5 篇的自动化工作流（40 分钟录播 + 30 分钟动手）**
- 批量内容生成模板 → 自动定时发布 → 数据回传（阅读数/转发数）
- 产出：5 篇草稿自动生成 + 截图打卡

**课时 4: 数据分析 + 选题迭代（30 分钟录播 + 20 分钟动手）**
- 分析已发布帖子的数据 → 自动挑高传播选题 → 生成下一批选题
- 产出：3 个基于真实数据的新选题 + 截图打卡

## 模块 4: 数字人直播入门（¥799 | 3 天录播 + 每天 30 分钟 QA 直播）

> "模块 3 学完了内容生产。模块 4 教你怎么批量放大——数字人 7x24 直播卖课。"

### 前置条件
- 需要注册硅基智能（¥399/月，课程内提供注册引导但**不代注册**）
- 需要提前准备 5 张个人照片 + 2 分钟音频（用于形象克隆）

### Day 1（约 2 小时）
**课时 1: 数字人技术选型 + 硅基智能注册实操（30 分钟录播 + 20 分钟动手）**
- 市面 10 个数字人平台对比（硅基/蝉镜/腾讯智影/HeyGen/D-ID 等）
- 注册硅基智能 DUIX 3.0 → 上传照片 → 克隆形象
- 产出：硅基智能后台显示"形象已生成" + 截图打卡

**课时 2: 第一条数字人测试视频（40 分钟录播 + 30 分钟动手）**
- 写 3 分钟脚本（产品介绍 + 定价说明 + 逼单话术）
- 数字人驱动 → 检查口型 / 自然度 / 中文发音准确度
- 产出：一段 3 分钟测试视频 + 截图打卡

### Day 2（约 2 小时）
**课时 3: OBS 推流配置 + 首次直播（40 分钟录播 + 30 分钟动手）**
- 下载 OBS → 配置虚拟摄像头 → 加入硅基智能直播流
- 产出：OBS 显示"正在直播" + 截图打卡

**课时 4: 直播话术 + AI 自动弹幕回复（30 分钟录播 + 20 分钟动手）**
- 写完整话术脚本（开场 → 产品介绍 → 定价 → QA → 逼单 → 收尾）
- 配 AI 自动弹幕回复规则（20-30 条预置 QA）
- 产出：话术脚本 + 弹幕回复规则的文本文件 + 截图打卡

### Day 3（约 2 小时）
**课时 5: 课件制作——PPT + 屏幕录制素材（30 分钟录播 + 20 分钟动手）**
- 做 5 页 PPT（产品亮点 + 定价 + 案例 + 逼单 + CTA）
- 配 3 段屏幕录制素材（agent 安装过程的关键步骤）
- 产出：PPT 文件 + 录屏文件 + 截图打卡

**课时 6: 首次模拟直播 + 数据复盘（40 分钟录播 + 30 分钟动手）**
- 完整模拟一场直播（数字人主述 + AI 弹幕回复 + 真人盯转化节点）
- 数据复盘：观看人数 / 停留时长 / 转化率 / 加微信数
- 产出：复盘报告 + 改进建议 + 截图打卡
