# 对话明略吴明辉：AI 正在杀死 SaaS，但我找到了一条新路

## 核心判断

> "闭源已死，开源已来，从 token 和模型上赚钱。"

> "软件本身的价值已经接近于没有了。一个亿的 token，就能大体复刻别人历史上几十亿堆出来的东西。"

> "以前大家按人月、人天收费。将来会变成 'token 成本加管理费'。"

## 关键数据

- 吴明辉个人两周 token 费 1 万美元——"怎么这么便宜？那两周我怎么着也给公司创造了十亿的价值"
- 章鱼核心开发团队不到 10 人，两个多月生产近百万行代码
- 最高纪录一天 token 费 3.7 万美元，最厉害一个工程师一天消耗 8000 美元
- 5 个人 2 个多月做了"过去要投几千人干十年的事"
- 2020 年 EIP 失败：4000 人裁一半，至今不裁员

## 对 003 素材缺口的覆盖

### ① 中国企业 Agent 落地案例 ✅ 关键缺口补完

| 之前缺的 | 现在有的 |
|---|---|
| 中国企业用 agent 替代岗位的具体案例 | 明略全员日常在章鱼上工作，CEO 高频沟通 18 只龙虾 |
| 有数据支撑的 agent 效率提升 | 5 人 2 月做百万行代码，天耗 token 3.7 万美金 |
| 企业级 agent 的真实 ROI 判断 | "太便宜了"——不是成本问题，是 ROI 认知问题 |

### ② 多 Agent 网络的行业判断

- **MoE vs MoA**：模型公司做 MoE（预设专家分工），明略做 MoA（动态 Agent 协作）——"穷人有穷人的路"
- **Scaling Out vs Scaling Up**：不追求单体模型更聪明，而是"让一群普通模型协作起来，在细分战场打赢更大的单体模型"
- **"龙虾已经越过了能干活的基线"**——这个判断本身就是一个信号：企业级 Agent 已过临界点

### ③ Agentic Service 商业模式

- 从 SaaS 订阅制 → "token 成本 + 管理费"——直接呼应洞察一（DAU 困局）中"中国 AI 怎么赚钱"的讨论
- 软件开源 + 模型/数据赚钱——"开源越彻底，用的人越多，模型场景数据积累越快"
- 专业小模型（Mano 系列）+ 细分场景 99.9% 准确率
