## 关键叙事链

### 海外：Coding 是 AI 最赚钱的赛道
- Claude Code 增长超过 Salesforce、Slack 等软件企业早期增速
- Anthropic 靠 Coding 实现弯道超车，ARR 四个月翻三倍
- OpenAI 与 Anthropic 的核心战场在 Coding

### 中国：大厂抢人 + 创业公司先吃红利
- 郭达雅（DeepSeek Coder 第一作者、GRPO 发明人）近亿元年薪入职字节 Seed，任 Agent 负责人
- 阿里、腾讯、字节都接触了郭达雅
- 创业公司先一步：智谱 2025 年初以 Coding 为重点，GLM-5 连续涨价三次
- 字节此前训 Code 模型"上面都说最后一次了"——大厂之前投入有限，现在全面转向

### Agent 与 Coding 的融合
- "agent 的本质就是代码理解、代码生成、程序综合"
- 郭达雅离职 DeepSeek 的原因之一是"内部 Agent 优先级不高"
- 字节 Seed 启动针对 Agent 和 Coding 的组织整合
- 下一代模型的重点就是 Agent 能力优化
