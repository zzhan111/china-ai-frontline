- **双智能体架构**：理解者（中文语义理解98%准确率）+ 执行者（调用各专家模块）
- **Figma直接转代码**：像素级还原（实测2像素以内偏差）
- **原生中文**：不需要用英文描述需求，理解微信支付/小程序/公众号等中国特色概念
