# "龙虾"安全养殖手册，来了！

## 国家安全部的定性

官方将 OpenClaw 定性为"遵规守纪、产能高效的'数字员工'"——正面、官方、建设性的态度。

## 龙虾四条核心特征（官方定义）

1. **从"给出方案"到"落地执行"** — 不像大模型通过问答给建议，而是通过聊天程序远程执行指令
2. **从"固定功能"到"多种插件"** — 内置技能插件体系，覆盖多场景
3. **从"普通工具"到"自我进化"** — 长期记忆，"越用越懂用户"，所以叫"养"
4. **从"被动等待"到"主动服务"** — "夜间下达指令、晨间获取成果"
