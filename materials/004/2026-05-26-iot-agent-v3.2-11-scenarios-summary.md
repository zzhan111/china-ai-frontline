## 核心架构

基于 24,000 条真实交互链路训练，IoT-Agent v3.2 的核心范式是 **Thought → Action → Observation 的 ReAct 循环**。每个场景中，Agent 不自上而下按预设流程执行，而是在每个节点根据 sensor 反馈动态决策下一步。

---

## 11 个场景脉络

### 1. 室内环境调节
痛点：传统温控滞后（感到不适时身体已有反应），新风与空调各自为战。
ReAct 闭环示例：用户说"觉得闷"→ Agent 定位用户位置 → 读取 CO₂/温/湿度传感器 → 发现 CO₂ 1500ppm → 查询记忆发现"用户嫌高档噪音大"→ 中档新风 + 微开窗 + 循环扇组合。

### 2. 极致入睡场景
痛点："准备睡觉"是复合指令，涉及舒适 + 安防双重需求。
闭环：关帘调光调空调 → 自动安全自检 → 发现入户门未反锁、车库门开启 → 自动关闭并播报。

### 3. 烹饪辅助
痛点：多设备操作节奏紧张，易遗漏。
闭环：检索烹饪知识 → 预热烤箱 → 预判油烟，主动询问 → 烟雾/温度传感器监控 → 记忆用户偏好（五分熟）。

### 4. 卫浴体验
痛点：隐私敏感区（浴室）成安全盲区，摄像头方案不可用。
方案：毫米波雷达（无视觉，仅捕捉姿态）→ 无感监护跌倒检测 → 温和语音确认 → 逐步升级预警。

### 5. 娱乐影音
痛点：影院模式仅简单关灯开设备，缺综合感考量。
闭环：降幕布开机 → 检索 NAS/流媒体资源 → 人体传感器感知多人观影 → 自动开防直吹模式。

### 6. 安防应急
痛点：传统安防仅报警，无法主动处置。
闭环：燃气泄漏确认 → 关闭燃气总阀 → 强制全屋新风 → 语音播报逃生路径 → 自动联动物业。

### 7. 访客与物流
痛点：快递上门时用户不在，门禁安全与便捷难平衡。
闭环：摄像头识别非亲友 → 要求输入快递单号验证 → 生成单次有效 5 分钟临时门禁码 → 语音指引放快递柜。

### 8. 商业零售运营
痛点：门店启闭流程繁琐，多协议兼容难。
闭环：按营业/打烊 SOP 批量执行（安防 → 卷帘门 → 空调 → 展示屏 → 照明），Zigbee/Modbus 协议兼容。

### 9. 智慧养老看护
痛点：老人排斥智能设备，摄像头冰冷且有隐私问题。
闭环：老人静止 4 小时 → 不立即报警 → 查历史记忆发现是午睡习惯 → 预期起床时间后 15 分钟温和询问 → 未回应逐步升级。

### 10. 能源管理与优化
痛点：峰谷电价波动，人工难精准调度。
闭环：收到尖峰电价通知 → 扫描高能耗设备 → 空调调高 1℃ → 充电桩推迟至谷时 → 结合光伏判断用电/售电策略。

### 11. 政务与公共服务
痛点：涉密场景对安全与权限要求极高。
闭环："绝密会议模式"指令 → 物理切断录音设备网络 → 开启信号屏蔽器 → 锁定电子档案柜 → 关闭对外传输接口。全本地化部署。

## 关键结论

- Agent 不是靠预设规则做事，而是在每个感知节点上运行 **ReAct 循环**（Thought → Action → Observation），动态决策
- 核心价值不在"能控多少设备"，而在"能理解多少场景逻辑、解决多少实际痛点"
- 长效记忆（用户偏好 + 历史行为）是 Agent 从"被动执行"进化到"主动预判"的关键
- 全本地化部署 + 毫米波雷达等无感技术，解决隐私敏感场景的智能化难题
