## 行业痛点

传统智能家居停留在**"单步指令执行"**阶段：

1. **语义理解的断层**：说"准备睡觉"，可能只会关灯，不会检查入户门是否反锁
2. **被动的信息输入**：模型等数据喂到嘴边，不根据模糊需求主动探测
3. **破碎的记忆**：昨天的操作习惯今天忘

## 核心架构：ReAct（Reasoning + Acting）

IoT-Agent v3.2 彻底抛弃 If-Then，采用 **Thought → Action → Observation → Thought 循环**。

**最大杀手锏：主动感知（Active Perception）**

当用户需求模糊、信息不足时，模型不再瞎猜，而是主动调用 `sensor_radar` 或 `read_sensor`——从"被动执行者"进化为"主动探索者"。

## 两大技术支柱

### 1. 记忆系统
- **短期记忆（Session Memory）**：记录当前任务每一步 Trace
- **永久上下文（Permanent Context）**：存储用户操作习惯，跨场景调用；通过 `write_memory` 技能固化为经验，类似场景决策延迟降低 40%

### 2. 指令一致性
- 24,000+ 条完整交互链路（Agentic Trace）训练
- 技能调用参数错误率降至 0.5% 以下

## 全场景覆盖（摘要）

- **智慧养老**：浴室异常声音 → 传感器确认（隐私优先）→ 准备报警
- **商业零售**："准备开店" → 撤防、开卷帘门、调空调、开音乐、激活显示屏
- **能源管理**：峰谷电价通知 → 自动调 Eco 模式、暂停充电桩

## 未来方向

- 端侧部署优化：小参数量模型跑出 ReAct 逻辑
- 多模态感知：引入视觉 Skill，"看"到漏水、宠物拆家
- 群体智能：多 Agent 协同（家庭 × 社区服务）
- **最终愿景：主动式物联网时代**——模型像空气一样在你不经意间提供最恰当的照顾，AI 大面积走出计算机、走出虚拟世界，向现实世界落脚
