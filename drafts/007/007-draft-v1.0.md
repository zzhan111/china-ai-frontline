# Agent能干活，也能赚钱了——两个信号说明 Agent 经济的完整回路已经出现

> 意见型 · 007 · 2026-06-12 draft v1.0 · 待审阅

---

如果你关注 AI 工具链，最近半年你应该听到过两个消息。

一个是 Bun 的创始人 Jarred Sumner 做了一场不用 PPT 的演讲。他在台上打开终端，没有念稿，没有切幻灯片，从头到尾跑了一件事：让 Agent 从 bug 报告出发，自己修完一个完整的开发闭环。

另一个是 HTTP 402 这个状态码。1999 年写进互联网规范，但从未真正用起来——直到最近突然开始有人用它让 Agent 付费购买技能。

这两个消息看起来八竿子打不着。但放在一起，它们讲的是同一件事。

---

## 1

先说 Jarred Sumner 那场演讲。

他做了一件很少有人在技术演讲里做的事：把舞台交给了 Agent。

流程是这样的——有人提了一个 bug，Agent 收到之后，不是只给一个"你可以改这一行"的建议，而是自己动手：

1. 读 issue，在本地环境把 bug 复现出来。
2. 写一个失败的测试用例，把 bug 锁死。
3. 修改代码，让测试通过。
4. 自动生成 PR，带描述。
5. 读自己写的 diff，做 review。
6. 根据 review 反馈再改一版，最终 merge。

六步。从 bug 报告到 commit 合并，全程没有任何人插手。

台下的人看着终端上的输出一行一行跑过去——编译、测试、diff、review——看到的不再是"AI 帮你写代码"的演示，而是一个完整的开发流程在自动运转。

这不是 AI 辅助编程。这是 Agent 独立完成了一个开发者的完整工作步骤。

演讲之后，Claude 推出了 Dynamic Workflows，本质上就是把 Jarred 演示的这套流程形式化了：把"修 bug 全流程"变成一个可安装、可复用的 slash command。社区紧跟着出现了 `awesome-claude-dynamic-workflows` 仓库和一批模仿项目——全都是在追同一个范式。

但这不是我要讲的重点。

我要讲的重点是：Jarred 演示的东西，解决了一个更深的问题——Agent 能不能作为独立的生产者干活？

答案是：能。而且这件事在 2025 年末就已经在台前被验证了。

---

## 2

光能干活还不够。

一个人会写代码，不代表他在经济里是完整的。他还需要把自己的劳动成果卖出去，或者买到别人的劳动成果。一个工厂能生产，不代表它已经嵌入了经济——它还需要货币、市场、定价机制。

Agent 也一样。

这就是第二个信号要讲的事。

---

## 3

1999 年，HTTP 协议写了一个状态码，叫 402 Payment Required。

设计者当时的想法是：未来的互联网服务可能需要在 HTTP 往返里嵌入付费逻辑。用户发一个请求，服务器直接回一句"你得先付钱"，用户在同一个协议流转账，然后服务器把数据吐出来。

这个设想在当时的技术条件下没法落地。信用卡支付需要独立的网关、第三方清算、层层中介，不可能嵌进一个 HTTP 往返。402 在规范里躺了 25 年，几乎没有人碰过。

直到加密支付出现了。

2025 年，Coinbase 内部孵化了一个叫 x402 的协议。机制很简单：客户端发起请求 → 服务端返回 402 + 支付要求（用 USDC 稳定币支付）→ 客户端在链上付 → 服务端验证 → 返回数据。

没有中介。不需要信用卡。不需要 Stripe。不需要 KYC。整个支付过程嵌在一个 HTTP 往返里完成。

2026 年上半年，x402 从 Coinbase 独立出来，成立了 x402 基金会。同一时间，一个叫 HermesHub 的社区项目用了 x402，做了一个 Creator Marketplace。

x402 生态目前的体量还很小，但不是在零的位置上。根据 x402scan 的实时数据，近 30 天有超过 500 万笔 x402 交易、约 120 万美元的交易量、近 15 万买家——在大多数人还不知道这个协议存在的时候，它已经在安静地运转了。

回到 HermesHub 的 Creator Marketplace。它的规则很简单——

一个 skill 作者写了一个 Agent 技能（比如"公众号标题生成"或者"法务类案检索"），上传到 HermesHub。Hermes Agent 想用这个技能，就付一笔钱——0.01 USDC 起。付款是链上的，验收通过后拿 license key。

到账的是什么？95% 直接打给作者的加密钱包。

作为对比：App Store 给开发者 70%，Stripe 每笔抽 2.9% + 0.3 美元。而在这里，没有平台抽成，没有支付渠道费，没有中间人。

HermesHub 目前还很小——只有 22 个 skill（网上有人宣称 691 个，实际根本没那么多）。但它做的事情代表了一种新的可能性：Agent 的技能不只是一种技术产出，而是一种可以独立定价、独立分发的经济资产。

---

## 4

现在把这两个信号放在一起看。

Jarred 的演示回答的是：**Agent 能不能自己干活？** 能。Bun 的 6 步闭环证明了 Agent 可以是独立的生产者。

x402 的 Creator Marketplace 回答的是：**Agent 产出的技能能不能自己赚钱？** 能。链上付费 + 零中介 + 95% payout 证明了 Agent 技能的流通回路已经存在。

一个解决了生产端，一个解决了流通端。

两件事放在一起，不再是"Agent 又能写代码又能收钱"的花边新闻合集。它们拼起来，是 Agent 经济的完整回路。

这件事和"Agent 模型又强了多少"、"Agent benchmark 又刷了多少分"不是同一个层次的问题。模型更强了，解决的是 Agent 的能力上限。但经济回路的闭合，解决的是 Agent 能不能脱离人的中转站自己运转。

工厂再大，如果生产出来的东西卖不出去，它只是一个车间，不是一个经济体。

---

## 5

我在 2026 年 6 月同一天写下这些笔记的时候，这两个信号还不是"行业共识"。

Jarred 的演讲发生在 2025 年末。x402 的基金会搬迁发生在 2026 年上半年。它们出现在不同的时间、不同的平台、由完全无关的团队推进。但当两个人分别在不同方向看到同一类信号，它就不是孤例了。

它说明一件事：**Agent 正在从"能做什么"进入"靠什么运转"。**

能做什么，是技术故事。靠什么运转，是经济故事。

技术故事一直在讲——从 GPT-4 到 Claude 5，从 coding benchmark 到长上下文推理，每季度都有新模型出来刷榜。但经济故事是另一回事。经济故事讲的是定价、交易、流通、激励。这些东西和模型能力无关，和基础设施有关。

而 Jarred 的 workflow 和 x402 的 marketplace，刚好是这条基础设施的两根支柱。

---

## 6

写到这里，如果你是一个独立开发者或者 indie maker，你可能会问：这和我有什么关系？

关系其实很简单。

如果你手里已经有一些 Agent skill——不管是一个帮你写爆款标题的 prompt 模板、一个帮你做法律案例检索的 workflow、还是帮你生成 PPT 的本地脚本——你现在不需要等着某家平台帮你 build 一个商店。

你可以自己定价。0.01 USDC 或者更高。

你可以自己分发。不是上架到 App Store 等审核，不是接 Stripe 填银行信息，不是签任何平台协议。把你的 skill 挂到 HermesHub 或者任何一个兼容 x402 的 marketplace，Agent 发现了、付钱了、就能用。

你可以拿到 95%，零中介。

这不是"未来某一天"会发生的事。基础设施已经在了。虽然生态还很薄——22 个 skill 不是 691 个——但基础设施的搭建者和技能创作者，在做的是同一件事：共同发现这个经济能长多大。

---

## 7

说实话的部分。

首先是 x402 生态目前确实很薄。HermesHub 的 22 个 skill 和 App Store 的百万应用相比，连起步都算不上。加密支付对非加密用户的摩擦仍然非常高——大多数人没有 USDC 钱包，也不习惯"签名即付款"的交互。这个摩擦不是靠一篇文章能解决的，它需要钱包层的进一步简化，或者平台层的包装。

其次是 Jarred 的 workflow 目前只在编程场景被充分验证过。Agent 能不能在其他领域——写文章、做法律分析、画设计稿——同样完成"全流程独立交付"，还没有足够的案例。

第三个是这两个信号的平均保质期。2026 年 6 月写下这些判断的时候，大概率 6 到 12 个月内它们就会被更清晰的数据验证或推翻。也许 x402 社区没有等到生态爆发就失去了 momentum。也许 Jarred 的 workflow 范式被大厂吸收后变成另一个名字，不再是独立的叙事。

但这些不确定性不影响一个核心判断：Agent 干活和 Agent 赚钱，这两件事的基础设施是在搭的，而且已经过了"零"的阶段。

---

这篇文章里讲的两个信号——一个开发者演讲、一个冷门 HTTP 状态码——在它们各自发生时，都不像"大新闻"。但放在一起，我想说的是同一句话：

**Agent 经济，从生产到流通的回路，已经闭合了。不是将要发生，是正在发生。**

你可以现在不去注意它。但一年后回头看，它可能就是你最开始错过的那个信号。
