# 差了一个 Xometry

原创 之哲 [UIEVENTS事历]

2013 年，美国马里兰州一间小办公室里，几个工程师把一份 3D CAD 图纸上传到一个刚上线的网站。几十秒后，屏幕上弹出一个报价：CNC 加工，单价 $47，5 天内交付。

这是 Xometry 的第一笔交易。

那是一个 3D 打印零件。而今天，同一家公司 2025 年营收 $686.6M（同比 +26%），累计出货 1.65 亿个零件，连接了 82,000 个活跃买家和 5,000 个活跃供应商，覆盖 CNC、注塑、钣金、3D 打印、压铸等几乎全套制造工艺。

这件事本身已经足够不寻常——在这个"AI 时刻"，大家都在讨论 Agent 能不能干活的时候，这家公司已经用 AI 把"制造业报价"这个最古老、最依赖工程师经验、最难以规模化的手工活，做成了 API。而且它不是在给投资人画饼，它已经上市四年，每一个数据点都被 SEC 公开审计。

还有一件事：中国没有跑出同样量级的、纯市场化上市的 AI 制造平台。

这不是说中国没有制造业数字化。嘉立创从 PCB 起步，已经用即时报价模式服务全球电子工程师。RapidDirect 在深圳自建工厂，700 家供应商网络覆盖 120 个国家。它们做的是完全一样的事：上传 CAD → AI 报价 → 匹配产能 → 交付零件。

但嘉立创 2023 年深交所 IPO 失败了。RapidDirect 至今未上市。而 inbox 里列出的另外三家中国竞争对手 —— 云工厂、未来工场、速加网 —— 它们的域名要么失效，要么被抢注成了"琵琶影院"。

同一个赛道，中美走出了完全不同的结果。Xometry 靠什么跑通了？它的对手为什么活成了三种完全不同的样子？中国差的那一口气，到底差在哪？

---

## 一、一个靠报价引擎上市的公司

Xometry 摆在台面上的数字足够让人重新理解什么叫"AI 驱动"。

2025 年，它靠 Marketplace 业务（即时报价 + 按需制造）收入 $629.6M，同比增长 30%。这个 GMV 是由 AI 报价引擎驱动的 —— 客户上传 CAD 图纸，AI 在几秒到几分钟内完成几何特征识别、可制造性分析、工艺推荐，然后给出不同数量梯度的价格和交期。

不是人工估价。不是查价格表。不是"请联系我们获取报价"。

是即时报价。就像你在淘宝上看到商品价格一样，只不过你买的东西是一个需要 CNC 五轴加工的精密零件。

这个引擎的核心能力不是"AI 算法好"。Xometry 在 SEC 10-K 里自己说得清楚：算法是 proprietary machine learning，12 个专利加 2 个待批，覆盖几何特征识别、价格预测、材料选择。但算法本身在过去五年里门槛大幅降低了 —— CAD 文件解析、几何特征提取、工艺匹配规则，现在开源社区都能做到基本水平。

护城河是数据。

Xometry 从 2013 年开始，每一笔交易都在产生"配对数据"：一个 CAD 模型，加上 AI 给的报价，加上工厂实际生产成本，加上供应商的交付表现，加上质检结果。十年下来，这个配对数据集的规模是 1.65 亿个零件、"hundreds of millions of data inputs"（10-K 原话）。

新入局者即使有同样的 AI 技术，没有这个数据集也报不准价。报低了亏钱，报高了丢单。

更关键的是，Xometry 不是"制造业的 Uber"。这句话经常被用来形容它的平台模式，但它在 S-1 招股书里说得清楚：它是以卖家身份和买家成交，再向供应商网络下采购单。它自己承担库存风险和品质担保，赚的是"买家付款 - 供应商成本"的差价，不是抽佣。

所以它的 Marketplace Gross Margin（34.7%，2025 年）不是"平台交易费"，而是它用 AI 报价比供应商实际成本报得更准时赚取的定价溢价。

这条路它走了十二年。毛利率从 2018 年的 17% 一路涨到 2025 年的 34.7%。Q1 2026 年净亏损已经收窄到 $(5.3)M（一年前是 $(15.1)M）。按照这个趋势，2027 年之前很可能扭亏。

## 二、四个玩家，三种活法

这条赛道上有四个典型玩家，三种完全不同的活法。

**Pure Marketplace。Xometry。**

不建工厂，不做设备投资，只做 AI 报价引擎 + 供应商网络匹配 + 平台品质担保。资产轻，毛利率持续扩张，增速高（+26%），但仍在亏损边缘。

**Hybrid，自有工厂 + 网络。Protolabs。**

1999 年创立，比 Xometry 早十四年。它用自有工厂做注塑、CNC、3D 打印、钣金，2021 年收购了 Hubs（曾是 Xometry 最直接的欧洲竞品），改名 Protolabs Network。

Protolabs 2025 年营收 $533.1M，增速只有 6%。但它已经盈利了：净利润 $21.2M。它有 60 项专利，累计评估过 1,800 万个零件设计（Xometry 的十分之一）。

它的瓶颈很清楚：自有工厂是重资产，规模经济有上限。过去两年它的 customer contacts 连续下滑（53,000 → 48,000），单个客户收入在上升（$9,400 → $11,000）——说明它在"减量提质"，从增长模式转向盈利模式。但增速 6% 告诉市场：这个赛道，hybrid 的天花板已经到了。

**Hybrid，自有微工厂。Fast Radius。**

2017 年创立，Chicago 总部，CEO 来自麦肯锡 Industry 4.0 负责人。Chicago 和 Louisville 两间微工厂，加上 curated 第三方供应商，叙事和 Xometry 完全一致：AI 驱动的 Cloud Manufacturing Platform，机器学习 DFM 反馈。

但结局是：2021 年 SPAC 借壳上市，2022 年退市，累计亏损 $123M。死在两件事上——建工厂烧钱比 marketplace 快得多，而四年只积累了 8.5 万个设计数据（Xometry 的 1/2000）。数据不够 → 报价不准 → 客户留不住 → 烧穿。

**Hybrid，私募。Fictiv。**

和 Xometry 同年创立（2013），累计服务 6,000 多家企业，零件累计 4,200 万个，覆盖 5 个制造区域（美国、中国、印度、日本、墨西哥）。Honeywell 是它的标杆客户（"7x faster development"）。但 6,000 家客户 vs Xometry 的 82,000 活跃买家，差了 13 倍。

这四家公司放在一起，结论很清楚：Pure marketplace 是这条赛道唯一被验证的规模化路径。Hybrid 可以活下去（Protolabs），可以生存（Fictiv），但跑不快。Hybrid + 微工厂（Fast Radius）直接死了。

## 三、中国不是没人做，是做不大

如果你搜"中国 Xometry"，会看到很多人说"嘉立创就是中国的 Xometry"。这个说法对，但差一口气。

嘉立创的商业模式确实和 Xometry 高度同构：在线上传文件 → 即时报价 → 标准化制造。但它强在 PCB（印刷电路板），因为 PCB 的工艺参数极其标准——铜厚、线宽、层数、孔径、表面处理——这些都是规则引擎可以直接处理的。

可 Xometry 真正发力的地方不是 PCB。而是 CNC、注塑、钣金、3D 打印——这些非标工艺，零件的几何形状千变万化，同一个零件可以用多种工艺做，每种工艺的成本结构完全不同。AI 在这里要做的不是"查价格表"，而是"看这个孔多深，壁多薄，曲面多复杂，判断应该用 CNC 还是 3D 打印，再用 ML 估算工时和材料成本"。

嘉立创有 JLCCNC 和 JLC3DP 两个子站在做这些。但它目前还停在参数化报价阶段：选材料、选工艺、选尺寸、系统报价 —— 这是一个更靠近规则引擎的阶段，还没有进入 Xometry 那样的"几何特征 AI 识别 + ML 成本推理"。

另一个更接近 Xometry 的中国公司是 RapidDirect。深圳自建工厂，700 家供应商网络，2 万多全球客户，覆盖 120 个国家，40 多种材料和 20 多种表面处理。它的官网上直接写着"Get instant pricing and detailed DFM feedback in seconds"，和 Xometry 一模一样。

但它有几个特征值得注意：第一，它的客户是全球英语客户，不是中国本土客户。这说明它在做的其实是"把中国工厂产能卖给全球工程师"，而不是"解决中国制造业内部的报价效率问题"。第二，它自建工厂再加 700 家供应商，是 hybrid 模式 —— 这也限制了它资产端的轻盈度。第三，它还没上市。第四，它 2026 年上线了 AI Creator Lab——用文本描述直接生成 CAD 图纸——这是往 agentic 方向试探的信号，但离 Xometry 级别的配对数据飞轮还远。

真正让人意外的是 inbox 里列的另外三家：云工厂、未来工场、速加网。上周我验证了它们的域名，结果如下：

云工厂（yunfactory.com）→ 已被 HugeDomains 接管，域名转售中。
未来工场 → DNS 解析失败，无法访问。
速加网（sdjingong.com）→ 域名被抢注，变成了一个叫"琵琶影院"的在线视频网站。

三家全死。

这其实是这个故事里最残酷的部分。不是中国没有聪明的创业者，也不是中国没有制造业基因。而是这条赛道的死亡率太高了 —— 你需要在 AI 精度、供应链网络、客户信任和资本市场四个维度上同时过关，任何一个维度塌了，整条船就翻了。

## 四、三个结构性约束

同一条赛道，中美走出了完全不同的结果。这个问题不能简单用"技术差距"或"创业者不行"来回答。真正卡住脖子的是三个结构性约束。

**第一个：数据共享。**

Xometry 的 AI 报价引擎能越来越准，不是因为它的算法比其他公司领先太多，而是因为它有十年来从不间断的配对数据流：每一笔交易同时生成 CAD 模型、AI 报价、实际生产成本和质检结果。这种数据积累是时间函数，资本买不来。

在中国，工厂报价数据是极度分散的。一个 CNC 车间的报价方式可能和隔壁车间完全不同：有的按公斤计价，有的按工时计价，有的"老板看心情"。这些数据没有标准化，没有平台化，没有共享机制。

说到底，AI 报价引擎需要的是报价数据，而不是制造能力。中国不缺制造能力，珠三角、长三角的产能密度全球第一。但产能密度高不等于报价数据集中。恰恰相反，分散化的产能产生分散化的报价数据。没有平台聚合，AI 没有可以学习的对象。

**第二个：客户信任。**

Xometry 能跑通，一个常被忽略的原因是：美国的企业采购流程本身就是数字化的。SOW（工作说明书）、NDA（保密协议）、平台 API 集成、Punchout 采购接口、ERP 系统对接 —— 这些基础设施在美国已经成熟了二十年。Xometry 的 Teamspace（团队协同采购工具）和 Punchout（ERP 集成）之所以能成为 growth driver，是因为客户本来就在用这些工具。

在中国，制造业采购的核心逻辑是"关系"。老板拍板、看厂验货、酒桌文化、熟人转介绍。不是说中国制造业不想数字化，而是数字化的起点不是"没工具"，是"不信任"。在这种信任结构下，一家 AI 平台说"你不需要去工厂看，我来替你做品质担保"，很难在短期建立信用。

RapidDirect 的选择印证了这一点：它不主攻中国本土市场，而是用中国工厂产能服务全球英语客户。那些海外客户的信任习惯和对 AI 报价的接受度，已经在美国公司那里被教育过了。

**第三个：资本市场。**

Xometry 2021 年上市时，它在 S-1 里明确写了"we have incurred net losses in the past, expect to incur net losses in the future and may never achieve or maintain profitability"。换成 A 股上市申请材料，这段话会被直接毙掉。

中国资本市场对亏损上市的容忍度极低。嘉立创 2023 年深交所 IPO 失败，和这条规则高度相关。而 Xometry 这种"长期亏损换增速"的模式，需要的是一个愿意接受"你现在不赚钱，但你有 1.65 亿个零件的数据飞轮、34.7% 的毛利率年年涨、81,000 活跃买家年增 20%"的资本市场。

VIE 架构限制、中美关系紧张、数据跨境监管 —— 这些对中国制造业 AI 平台出海上市的每个环节都施加了额外摩擦。不是完全不可能，但"时间窗口"和"容错空间"都比美国赛道窄很多。

当然，这三个约束不是完整解释。任何一个国家层面的产业差异都有几十个变量在同时作用——政策、教育、文化、地缘。这三个是本文基于 Xometry 赛道最显著的结构性对照，不是唯一解释。

## 五、这不是 Agent 经济，但它是 Agent 经济的前身

标题里说"007 Agent 经济回路文章的对照案例"，这里需要做一个区分。

Xometry 的 AI 报价引擎是 ML pipeline，不是 LLM agent。它做的事是：CAD 输入 → 几何特征提取 → 工艺规则匹配 → ML 成本预测 → 报价输出。这个 pipeline 里没有语言模型，没有工具调用，没有 agentic workflow 中的自主决策和错误恢复。

但 Xometry 做到了 agent 经济最想做的一件事：**把工程师的知识工作做成了 API。**

传统制造业里，一个有经验的工程师读一份 CAD 图纸、判断用什么工艺、估出合理报价，需要几年甚至十年的经验积累。Xometry 把这件事做成了"上传文件 → 即时返回报价"——这就是"知识工作 API 化"的极致案例。

Agent 经济要做的也是这件事。只不过 Agent 经济想用 LLM 把更多类型的知识工作 API 化 —— 不只是制造报价，还有法律分析、软件开发、金融建模、药物研发。Xometry 证明的是，在"必须有确定性结果的 B 端场景"下，这条路可以跑通，而且可以跑成一家营收 6.86 亿美元的公司。

但它同时给 Agent 经济提了一个醒：跑通的条件非常苛刻。

你必须有一个足够大的配对数据集（CAD × 报价 × 生产）。你必须有足够高的容错率（制造业报价差几个点不会死人，但差 50% 就丢单）。你必须有足够长的积累周期（Xometry 用了十二年）。你必须在资本市场上找到一个愿意为数据飞轮付费的故事。

这些条件放在 Agent 经济里，意味着：不是所有"知识工作"都适合被 API 化。那些没有标准化产出、没有验证闭环、没有积累配对数据的领域，Agent 很难做到 Xometry 级别的精度。

这其实不是 Xometry 独有的模式。医疗 AI 诊断领域也面临同样的结构——肺结节检测的 AI 精度能在 Mayo Clinic 达到 94%，靠的是数百万张标注 CT 影像的配对数据集，不是什么黑箱算法。B 端 AI 的确定性，永远建立在配对数据的积累之上。

## 六、平台的正确打开方式

前段时间我在写 Agent 经济回路的时候，一直在想一个问题：为什么蚂蚁 AI 支付、Character.AI、Devin 这些 agent 产品还在"能不能跑通"的阶段，而 Xometry 这个非 agent 的 AI 产品反而已经上市四年、接近盈亏平衡了？

答案可能很简单：确定性。

制造业的报价是一个高确定性的问题。零件的几何特征是可以精确描述的。工艺成本是可以通过大规模配对数据训练逼近的。供应商的交期是可以通过历史表现预测的。质检标准是 ISO 可以量化的。

而 agent 要解决的问题 —— 写代码、做法律分析、做金融判断 —— 每一个都有比制造业报价大得多的不确定性。不是 AI 不行，是问题的结构化程度不同。

所以 Xometry 这个故事，不是"AI 颠覆制造业"，而是"AI 在结构化程度最高的 B 端问题上先跑通了"。这可能是一个更准确的信号：Agent 经济的真正爆发，不一定从最高不确定性的领域开始（像通用 Agent），而可能先从类似制造业报价这样的高结构、有验证闭环、可积累配对数据的垂直领域开始。

在这个意义上，Xometry 不只是一个对标榜样。它提示了一件事：AI 平台经济，可能不是从最热闹的地方开始的。
