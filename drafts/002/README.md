## 一、v1.1 → V2 的修改要素总览（七大类）

按"由表及里"的顺序列出。

### 1. 标题与导语层：从"内部读者信"到"通用号召"

| 维度 | v1.1 | V2 |
|---|---|---|
| 导语收件人 | "写给 UIUC 校友、在美华人工程师……" | 删除具体收件人，改为"今天这篇文章不谈 AI 带来的宏大叙事，只讲一件有用的事情" |
| 导语核心问句 | "第一批真实用户，到底从哪里来" | 新增灵魂拷问"**你能不能让身边的人为你的产品花钱？​**" |
| 节标题 | "一、引子：声量最大的两件事……" | 删除"引子"前缀 |
| 第二节标题 | "二、为什么是教育 AI：你身边正在发生的需求……" | 只保留"你身边正在发生的需求……" |
| 第三节标题 | "三、为什么是华人团队：被低估的……" | 只保留"被低估的……" |
| 第九节 | "九、给 UIUC 受众的三句话" | 整节删除 |

**潜在原因**：v1.1 是带强烈"圈层定位"色彩的稿子；V2 把所有"内圈黑话"和"小而美的收件人名单"都剥离，把文章从"写给某群人"变成"写给所有可能在做 AI 创业的人"。这是一次明显的**公众号化转型**。

### 2. 引子时代背景：从"出海叙事"到"中美模型差距叙事"

v1.1 谈 AI 出海是"我们怎么走出去"的视角；V2 改为"中美对标、差距与领先"的视角。Agent 三件套从 "Computer Use、Coding Agent、**Deep Research**" 改成 "Computer Use、Coding Agent、**Auto Research**"。讨论 AI 群也从"中文 AI 群、播客、newsletter"扩展到"AI 群、公众号、播客、**X**"。

**潜在原因**：2026 年中这个时间点，"中国 AI 出海"已经从一个新鲜话题变成了一个旧叙事，真正在被讨论的是"中美模型差距收敛"和"Token 调用量"这种更具体的产业指标。

### 3. 身份去标签化：UIUC / FLAGG / 大厂 的层层退场

| 位置 | v1.1 | V2 |
|---|---|---|
| 引子段 | "UIUC 读书的学生 / 北美大厂出来的华人工程师" | "校园里念书的学生 / 工位上跑着 Claude Code 却想着自己东西的工程师" |
| 第一节 | "出海赛道里的明星位置" | "中美大模型竞赛的赛道上也已经占满了巨人" |
| 第一节 | "Agent 能力跑分榜上的玩家" | "智能体框架赛道上的玩家" |
| 目标读者句 | "UIUC 校友、在美工程师、想出海创业的华人技术人" | "留学背景的学生创业者/海外大厂程序员" |
| 第二节 | "UIUC 读书的学生 / 北美大厂出来想做自己东西的华人工程师" | "还在读书的留学生 / 还没有特别好创业点子的 **FLAGG 打工人**" |
| 第七节 | "真正稀缺的不是会**调模型**的人" | "真正稀缺的不是**只会写代码**的人" |
| 第七节 | "我们也会调模型" | "我们工程能力强" |
| 第七节 | "团队" | "团队/超级个体" |
| 末节场景 | "UIUC 的某间教室里" | "美国大学的某间教室里" |

**潜在原因与规律**：

- **UIUC 全文消失** —— 把一所具体高校的圈层暗号，换成"美国大学"这种更宽的能指。
- **​"调模型"两次出现都被改掉** —— 把批评对象从"模型工程师"扩大到"广义技术人"，**不冒犯任何具体的技术身份**。
- **FLAGG 取代"北美大厂"​** —— 更精确、更圈内（FAANG 的 2026 版本变体）。
- **​"超级个体"新增** —— 这是 2026 年 AI 创业语境的关键词，承认 Agent 时代单人创业的可能性。

### 4. 论证结构：从"问题驱动"到"现实驱动"

v1.1 第四节用了一段明显的"过渡总结+预告"（"写到这里，'为什么是教育 AI'和'为什么是华人团队'算是回答完了……"），V2 把这一整段砍掉，正文直接进入"但有了方向、也有细分的市场可以切入，最现实的问题立刻摆在面前……"。

第四节的"教育 AI 获客逻辑"段落也做了**深度白话化重写**：

| v1.1 | V2 |
|---|---|
| "和企业 SaaS 完全不同。它没有'销售线索'，也很难靠付费广告跑通 ROI——学生用户的客单价撑不起 CAC。它真正能用的，是几条**和产品形态深度耦合的高密度渠道**" | "既不是 to B 那套靠销售去谈的打法，也不是 to C 那套直接打广告买流量的打法，因为从每个学生身上赚的钱，可能还不够付广告费的。因此，**它的获客方法注定依靠这几种和产品长在一起的渠道**" |

**改动要素**：删除大纲式过渡；删除 ROI / CAC / SaaS / 耦合等术语黑话；用"to B / to C 打法""产品长在一起"等生活化表达替换；破折号被改成"因为……"的因果连接。

### 5. 第五节：从"嵌入流程"到"嵌入场景"

v1.1 第五节标题"嵌入学习**流程**的深度：决定你会不会被'**一个 ChatBot 链接**'替代"，V2 改为"嵌入学习**场景**的深度：决定你会不会被'**通用 ChatBot**'替代"。整节里所有"节点 / 流程"基本都被替换为"场景"。

### 6. 句式与标点：去掉破折号、用"因为"代之

V2 系统性地处理了 v1.1 中破折号引出的解释性从句，同时**列表项之间增加了空行**，让公众号阅读体验里每一项呼吸感更强。

### 7. 概念词替换：去专业化、去术语化

| v1.1 | V2 | 性质 |
|---|---|---|
| "**非模型能力**" | "**业务逻辑能力**" | 否定式 → 正向定义 |
| "**华人团队**" | "**华人基因创业团队**""**华人基因迁移优势**" | 增加"基因"的文化继承隐喻 |
| "**海外**学生 / **海外**" | "**美国**学生 / **美国**" | 具体化地理坐标 |
| "作业帮、猿辅导、网易有道、扇贝、流利说这样的公司" | "作业帮、猿辅导、网易有道**等等**公司" | 缩短列举、降低密集感 |

## 二、V2 → Preview 的最后一轮微调

Preview 是发送前最终预览稿，相对 V2 的改动更克制，主要解决了 V2 留下的两个轻微副作用，并对几处文案做了最后的口语化与具象化处理。

### 1. 标题与开篇：从"号召式问句"到"动作式承诺"

| 位置 | V2 | Preview |
|---|---|---|
| 文章主标题 | （灵魂拷问式开场）"你能不能让身边的人为你的产品花钱？" | **​"让美国学生愿意掏出真金白银为你做的 AI 付费。"​** |
| 核心承诺 | 抽象的"身边的人 / 产品 / 付费" | 具象的"美国学生 / 真金白银 / 你做的 AI" |

**潜在原因**：V2 的灵魂拷问适合在文章中段做转折，但作为公众号标题/开篇过于抽象。Preview 把它改成一个画面感极强的陈述句——**主语（美国学生）、动作（掏出真金白银）、对象（你做的 AI）三件事齐全**，公众号点进来的读者三秒就能判断这篇文章和自己有没有关系。

### 2. 修复 V2 遗留的"FLAGG"不一致

V2 里 UIUC 被彻底删除，但 "FLAGG 打工人" 这个圈内黑话却保留了下来，导致身份去标签化不够干净。

| V2 | Preview |
|---|---|
| "还没有特别好创业点子的 **FLAGG 打工人**" | "还没有特别好创业点子的 **北美大厂打工人**" |

**潜在原因**：把 FLAGG 这种 2026 圈内变体回退到"北美大厂"——更通用、不依赖读者识别 FAANG 缩写，与全文"去圈层符号"的方向终于一致。

### 3. 修复 V2 遗留的"海外 → 美国"过度替换

V2 把所有"海外"都改成了"美国"，虽然更具体，但末段失去了"海外华人 AI 创业"的命题感。Preview 在末段做了一次平衡：

| V2 | Preview |
|---|---|
| "下一个跑出来的人，也许就在**美国大学**的某间教室里。" | "下一个跑出来的人，也许就在**我们大学**的某间教室里，或者在**某个北美华人晚上下班后打开的 IDE 里**。" |

**潜在原因**：

- "我们大学"比"美国大学"更带**情感共振**——"我们"把作者和读者拉到同一阵营。
- 新增"北美华人晚上下班后打开的 IDE 里"这个第二落点，把"教室"独大的画面扩展为"学生 + 工程师"双场景，呼应文章开头那两个收件人，闭环更完整。

### 4. 第五节 ChatBot 类比的进一步聚合

| V2 | Preview |
|---|---|
| 标题"决定你会不会被 **​'通用 ChatBot'​** 替代" | 标题"决定你会不会被 **​'通用 Agent'​** 替代" |
| 正文"所有不深度嵌入学习场景的产品，最终都会被**通用大模型**一句话替代" | 同 |
| 正文具象产品 "**ChatGPT 或者豆包**" | 保留 |

**潜在原因**：把节标题里的"通用 ChatBot"升级为"通用 Agent"，呼应了文章第一节就建立的"AI Agent 的能力边界"叙事——首尾对仗。具象层（ChatGPT / 豆包）保留在正文里，抽象层（Agent）放在标题，分工更清晰。

### 5. 第六节"学期节奏"段落新增结构化加粗

Preview 把第六节的四条要点都做了**首句加粗**处理（"用学期节奏""让学习资产沉淀""用同伴效应""为家长设计独立的价值证明"），并新增了一句重要的概括："**留存和获客在教育 AI 里是同一件事。​**"

**潜在原因**：四条要点在 V2 里是平铺的散段落，读者扫读时容易丢失主干；加粗+口号化让公众号场景下的"半阅读"用户也能拿到核心结论。新增的那句"留存和获客是同一件事"是全文为数不多的可截图金句，明显是为分享场景准备的。

### 6. 第七节标题：进一步去"模型化"

| V2 | Preview |
|---|---|
| "真正稀缺的不是**只会写代码**的人 / 是同时懂学生、懂渠道、懂订阅" | "真正稀缺的不是**会写代码**的人 / 是同时懂学生、懂渠道、懂订阅" |

去掉了"只"字。**潜在原因**：V2 的"只会写代码"带轻微贬义（暗示"代码以外不会"），Preview 删掉"只"字后，批评对象从"局限的程序员"变成"任何会写代码的人"，包括读者自己——**让读者从被批评对象变成被点醒对象**，姿态更平等。

### 7. 末段收束句精简

V2 末段以"也许就在美国大学的某间教室里"收尾后还有解释性文字；Preview 改为更短的两句独立收束：

> 下一个跑出来的人，也许就在我们大学的某间教室里，或者在某个北美华人晚上下班后打开的 IDE 里。
>
> 而决定它能不能跑出来的，从来不是它接入了哪个模型，写了什么样的代码。

**潜在原因**：两句独立成段、没有连接词，公众号排版下视觉重量更足，是典型的"金句结尾 + 反向重申"组合。

## 三、三版演进背后的写作原则

把 v1.1 → V2 → Preview 三版放在一起，能看出**三条贯穿性写作原则**：

### 规律一：从"圈层文章"走向"公共内容"

v1.1 的隐含读者是"UIUC 校友圈 + 在美华人技术圈"——它在导语就把读者圈死了，在节标题里用"为什么是 X"的提问式结构，在结尾给"UIUC 受众的三句话"做内部叮咛。

V2 拆掉了大部分圈层符号，但留了一个 FLAGG 的尾巴。**Preview 把 FLAGG 也回退成"北美大厂"，并在末段重新引入"我们大学 / 北美华人 IDE"这种"群体认同"而非"机构认同"的表达**——既保持公共传播半径，又不至于完全失去华人创业者的代入感。

### 规律二：从"产品经理腔"走向"白话叙事"

v1.1 是"产品经理 / VC 投资笔记"写法：ROI、CAC、SaaS、深度耦合、销售线索、嵌入流程、嵌入节点、模型能力假设、反馈链路……V2 的处理是**保留概念、替换载体**：

- ROI 和 CAC 的本质是"赚的钱够不够付广告费"——直接说后者。
- SaaS 的本质是"to B 销售那套打法"——直接说后者。
- "深度耦合的高密度渠道"的本质是"和产品长在一起的渠道"——直接说后者。
- "学习流程的节点"的本质是"学习场景"——直接说后者。
- "通用 ChatBot"的具体化是"ChatGPT 或者豆包"——直接说后者。

**Preview 把这条规律推到标题层**：把抽象的"你能不能让身边的人为你的产品花钱"变成具象的"让美国学生愿意掏出真金白银为你做的 AI 付费"——主语、动作、对象全部落地。

写作原则可以总结为：**当一个专业词的解释比这个词本身更短、更生动时，就用解释替代专业词**。

### 规律三：从"作者立场"走向"读者立场"

很多看似细碎的改动，其实都指向同一件事——**把作者的写作脚手架（大纲、过渡、自我总结）从文章里清出去**，让读者直接面对内容本身。

V2 阶段做了大部分清理（删"引子""为什么是 X"章节命名、删"写到这里……算是回答完了"过渡段、删"给 UIUC 受众的三句话"总结节、列表加空行、破折号改因果连接词）。

**Preview 进一步把"作者讲完话"变成"读者拿到金句"​**：第六节加粗四要点 + 新增"留存和获客是同一件事"、第七节去掉带贬义的"只"字、末段改用独立短句收束。这些改动都不是写给作者自己看的，而是为了**让读者在公众号场景下扫读、截图、分享时有钩子**。

一句话总结：**好的文章不应该让读者看见作者写作的过程，只应该让读者看见结论和论据；好的公众号文章还要让读者在三秒内决定是否要分享。​**

## 四、最终版（Preview）核心钩子清单

供后续选题与 social 投放复用：

1. **标题钩子**："让美国学生愿意掏出真金白银为你做的 AI 付费。"
2. **认知钩子**：教育 AI 的反馈链路短、任务边界清、目标用户就在你伸手能碰到的地方。
3. **方法论钩子**：华人基因迁移优势 = 拍照搜题 / 题库训练 / 应试辅导 / 语言学习 / 学习工具 五条护城河的 AI 重组。
4. **增长钩子**：渠道和产品形态得是同一件事；用错渠道做错形态，必然"花了钱、来了人、留不下来"。
5. **留存钩子**：留存和获客在教育 AI 里是同一件事。
6. **金句收束**：决定它能不能跑出来的，从来不是它接入了哪个模型，写了什么样的代码。
