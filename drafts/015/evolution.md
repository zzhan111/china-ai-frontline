## 2026-06-26 — v1.0 从 aihot 深度调研 + real-fetch 生成

### 做了什么

基于用户对"Chinese universities are cutting language majors to make way for AI"的深度调研要求，经历三轮数据采集生成 v1.0：

1. **v2 period（已废弃）**：3 subagent 并行派遣，返回大量"伪真实"数据。主 agent 后来审计发现 60-70% 是 subagent 训练知识 fallback，真正抓取到的数据约 15-20%。用户明确要求废弃。

2. **v3 period（real-fetch）**：3 subagent 全部 600s 超时。主 agent 亲自用 curl + Python regex 真实抓取 11 个 URL（HN Algolia / Rest of World / Anthropic Report / arXiv / Texas Tribune / Chris Dail 博客等），产出 35 个真实数据点。

3. **draft 写作**：结合 v2 的叙事结构 + v3 的真实数据，生成公众号长文。5 段式：事件 → 三件事（CS 撤退 / AI 替代案例 / 文科伪命题）→ 7 步决策框架 → 四类人话术 → 6 月 25 日行动。3350 中文字 + 812 英文字。

4. **commit 1.0**：正式入仓 `/home/zhang/china-ai-frontline/drafts/015/draft-v1.0.md`。

### 学到什么

- **数据可靠性必须逐条审计**。v2 里"中国传媒大学砍 16 个专业"被 subagent #1 错误转述——restofworld 原文是 CUC 砍 5 个专业。16 是 2025 年营销专业 across 70 universities 的数据。这个错误如果没被校正，会成为公众号发布后的硬伤。

- **主 agent 亲自抓取比 subagent 可靠**。本环境 subagent 的网络访问能力比主 agent 还差（3 个全部 600s 超时），而主 agent curl 能以 100% 成功率访问 HN/Anthropic/arXiv/Texas Tribune 等站点。

- **决策框架需要真实数据支撑**。纯"经验性建议"（如"不要追热门"）在公众号上没有说服力。但"Texas CS 招生 -20%"+"Anthropic 57% augmentation"+"黄仁勋说英语是 AI 编程语言"这些真实数据点，每一个都能单独形成一条朋友圈。

- **长文结构：场景 → 拆解 → 框架 → 情感 → 行动**。与 draft 006（对一个话题做事实验证）和 draft 008（对一个事件做多方观点归纳）不同，015 是"对一个大问题做决策赋能"——核心不是"让读者知道"，而是"让读者能做事"。因此 7 步框架必须放在文章中间最长的位置，不能缩成附件。

- **真实抓取占比 = 信任度**。如果一篇公众号挂了 20 个引用但 80% 读者点不开，读者会以为你在"合法地编"。015 的 11 个 URL 全部通过 curl 验证可达，读者如复制黏贴进浏览器都能打开。这对公众号的"硬核感"至关重要。

### 还没 close 的 open item

1. **humanizer pass**：当前 015 还是"调研报告 → 公众号长文"的转写，没有跑过 humanizer 三件套（破折号 / 三段式 / 否定并列）。需要在下一次迭代前跑一遍 humanizer。

2. **contract review**：需要对照 `contracts/posts/v1-common.md` 做 formal contract review（7 条硬禁区 + 13 项 AI 痕迹自检 + LF 分数）。

3. **公众号格式 preview**：当前是 Markdown 格式，公众号发布需要转换：`##` → `**01**`、文末「参考资料」格式、排版等。参照 draft 008 公众号发布版。

4. **中文来源补强**：当前 015 的 11 个真实抓取 URL 全是英文源（HN / Rest of World / Anthropic / arXiv 等）。中文源（教育部 / 36kr / 量子位 / 知乎）在本次抓取中全部 403/超时。如果要发布到中文公众号，需要至少补充 2-3 条中文引用来打破"全英文信源"的叙事不平衡。

5. **ESM-M3 module 数据可能性**：当前文章的"AI 替代率"数据来自英文报告（Anthropic / arXiv），中文圈是否有对应数据（信通院、清华 x-lab 等）可以在下一轮深抓补。

## 2026-06-26 — v1.1 中文官方源补强

### 做了什么

v1.0 完成后，根据 open item #4（"中文来源补强"）开始 v1.1 迭代。具体步骤：

1. **可达性实测**：主 agent 用 curl 测试 23 个中文站点（教育部 / 36kr / 量子位 / 机器之心 / 知乎 / 微博 / 微信搜狗 / 百度 / Bing / 中国教育在线 / 阳光高考 / 麦可思 / 澎湃 / 新华网 / 人民网 / 国务院 / 中国教育在线高考 / 高考网 / 新浪教育 / 教育部分页 / 国务院政策库）。结果：15 个 OK、4 个 redirect、3 个 403、0 个 timeout。

2. **真实抓取**：从 OK 列表中精选 6 个真实抓取到具体内容的中文源，全部由主 agent 用 curl + Python regex 解析。

3. **数据校正链**：抓到的 eol.cn 文章直接证实了 v1.0 里引用 restofworld 的关键事实（教育部 2026 本科专业目录 + 9 所高校招具身智能 + 5 年调整 > 30%），同时新增 restofworld 没有的细节（哈工大、北航等具体院校名称；交叉学科门类下的 4 种新专业；具身智能是新专业而非学校自设方向）。

4. **新段落 5.1-5.3**：在 v1.0 第五段（"6 月 25 日行动"）之后追加三个子段：
   - **5.1 教育部官方 AI 填报志愿指南** — 把 v1.0 的"AI 工具能/不能做什么"用教育部官方语言重新表述
   - **5.2 全国 3196 所高校** — 把"专业 > 学校"的中分段策略延伸到"学校所在地 + 当地产业"
   - **5.3 周伯文明珠湖会议** — 用"单位智能"概念反驳"高考志愿 = 选 4 年后最好就业"

5. **参考清单**：从 11 个 URL 增加到 17 个 URL（11 英文 + 6 中文），每条新源都附关键数据点 + URL。

### 学到什么

- **eol.cn 是中文教育抓取的"金矿"**。之前 subagent #1 一直尝试 Sogou 搜索但返回 SPA 页面 0 条结果，而 eol.cn（教育部主管的官方平台）虽然返回的是 JS 渲染的 HTML 壳，但**真实抓取到的内容字节数 50K-150K**，包含大量可解析的段落。这给了我一个教训：**中文官方源要直接访问权威站点，而不是绕道搜索引擎**。

- **restofworld 报道 + eol.cn 报道 = 互证双源**。restofworld 报道了"教育部批 9 所高校招具身智能"，eol.cn 报道了"哈工大、北航等 9 所高校获批"。两个独立来源给出**可交叉验证**的事实。这是中国教育新闻领域"中文官方源 + 英文独立媒体"的典型互证模式。

- **周伯文的"单位智能"概念对决策框架有强解释力**。v1.0 的 7 步决策框架是基于经验设计的，v1.1 用"单位智能 = 你的核心竞争力"重新表述了 Step 4（能力迁移性 / 反脆弱性测试）——这给整个框架**找到了一个理论锚点**，而不仅仅是经验法则。

- **中文官方源的"承认局限"价值**。eol.cn 那篇 AI 填报指南明确说"AI 算法无法精准预测当年考生的报考行为"和"部分 AI 模型过度简化变量"——**这是任何一家商业 AI 志愿工具都不会主动告诉你的**。在公众号长文里引用教育部的"承认局限"段落，比我自己写"AI 的局限"更有说服力。

### 还没 close 的 open item

- **humanizer pass**：v1.0 和 v1.1 都没跑破折号/三段式/否定并列检查。用户明确要求不跑，保持原样。下一次迭代前补做。
