# 我认识的 7 个 UIUC AI 校友,过去 12 个月里 4 个回国了——他们在赌什么

## 一句话价值主张

把"回不回国"这个抽象决策,降维成 7 个真实校友的具体赌注——让正在犹豫的原型 B 看到同辈在如何下注,以及下注的理由。

## 受众钩子

- **谁会转发**:UIUC 校友 + 任何海外华人 AI 工程师同辈群体(原型 B 的核心场景)
- **谁会收藏**:自己也在做这个决策、想反复看的人
- **谁会觉得"我以前不知道这个角度"**:把"回国"从宏大叙事,降到 7 个具体人 × 具体公司 × 具体赌注

## 核心论点 / 内容骨架

1. **开篇钩子**:不写"中美 AI 格局",写"我那个 IFC 旁边租房的师兄,上个月把车卖了回了北京"
2. **7 个人 7 个赌注**(可以匿名 / 化名,但要具体):
   - 例:"A,2019 UIUC CS,Meta 工作 5 年,2025 加入阶跃 → 赌的是基础模型还没收敛"
   - 例:"B,2021 UIUC ECE,Nvidia 工作 3 年,2026 初回国加入一家具身智能 → 赌的是中国硬件供应链"
   - 例:"C,留下来的人,在 Anthropic → 赌的是顶级人才密度复利"
3. **4 个回国的人共性**:不是"爱国"也不是"加班",而是 3 个具体共性(技术路线判断 / 决策窗口期 / 个人生命周期)
4. **3 个没回的人共性**:同样具体
5. **不下结论**,只列"如果你在做这个决策,你该问自己的 5 个问题"

## 关键素材 / 信源

- [ ] 至少 5-7 个真实校友访谈(可短可长,每人 15-30 分钟即可)
- [ ] 化名脱敏方案(让校友放心说真话)
- [ ] 时间线:每人"什么时候开始动念 → 什么时候 offer → 什么时候真走"
- [ ] 公司列表锚定:阶跃、月之暗面、智谱、MiniMax、宇树、银河通用、DeepSeek 这类被访谈对象提到的具体公司

## 风险与避坑

- **不能写成"回国劝退/劝进文"** → 调性必须中立、数据驱动
- **不要写成"我朋友们都很厉害"** → 是分析,不是炫耀
- **化名一定要彻底** → 校友圈太小,任何细节都可能反向定位
- **不打"爱国"或"撤退"的情绪牌** → 原型 B 反感站队
- **UIUC 锚点要自然** → 不要每段都提,开头收尾各一次就够

## 形式

- 主战场:公众号(2500-3500 字)
- 同步:X 中文长推 + Substack(英文摘要 + 链接回流公众号)
- 不发小红书(话题敏感度不适合)

## 为什么是复更首篇

- **同时打中原型 B 决策痛点 + 身份认同** → 转发率最高
- **不依赖现场资源** → 冷启动可控
- **建立"这个号在认真做事"的信号** → 平台和老粉同时感知
- **天然带"为什么我回来更新了"的潜台词**(因为我在观察这件事)→ 不需要单独写复更说明
