## 设计意图

**冷启动序列的核心材料。** 五篇覆盖三种内容类型（故事型、数据型、工具型），共同围绕一个暗线：**海外华人在中美 AI 之间的身份焦虑与务实选择**。

- 001：情绪锚点（为什么这个话题值得做）
- 002：工程信号（我们真的懂技术）
- 003：思想深度（我们看得懂技术分叉）
- 004：实用收藏（读者会保存并持续回流）
- 005：情感闭环（和 001 互文，完成"出走 vs 留下"双面镜）

发布顺序：001 → 002 → 003 → 004 → 005（月底收尾）

## 文件格式说明

每个草稿文件顶部的 YAML frontmatter 为元数据，含义如下：

```yaml
id:            草稿唯一编号（与文件名对应）
title:         草稿标题
pillar:        主要归属支柱（1-5）
secondary_pillar: 次要支柱（可选）
status:        状态：idea | draft | review | published
target_persona: 目标受众原型：A(研究者) | B(工程师/校友) | C(开发者)
uiuc_anchor:   是否含 UIUC 锚点
hook_type:     内容钩子类型：story | data | insight | utility | ...
role:          在序列中的角色定位
created:       创建日期
updated:       最后更新日期
```

## 合著规范

- 化名脱敏方案：至少姓氏不同，公司方向需模糊化（如"某具身智能公司"）
- 所有数字需可复核：时间线、API 定价、技术指标均需附信源
- 不站队：禁止"国产真香"或"海外必胜"倾向
