基于选题卡片 `topics/pillar-X/008-dario-policy-exponential.md` 和两份调研材料（`REPORT.md`、`dario-essay-text.md`），生成 v1.0 初稿。结构为七段递进式：Treebeard 切入 → 政策拆解 → "为什么是现在"（三件套脉络）→ 社区反弹三类归纳 → "Dario 可能对但这仍然危险" → 中文圈为何容易错过 → 方向盘收束。

2. 社区反弹段（原第三节）与产业定性段（原第四节）之间的"监管捕获"重复被消除。v1.1 中第三节只做社区情绪归纳（不评价），第四节独立做产业判断（制度竞争）。
3. 中文圈段落（原第六节）从独立章节压缩为结尾前的一段嵌入判断，不再单独成节，避免"附注感"。
4. 结尾从"方向盘"意象收束改为更锐利的产业判断："模型公司之间的竞争将从 benchmark 转向 regulatory framework。谁能把自己的安全框架变成行业标准，谁就能定义下一阶段的比赛规则"。

### 学到什么

- **热点调研型文章和访谈叙事型文章的结构逻辑不同**。访谈型（如 004）靠"人的故事 → 初心 → 实践 → 下一个想法"形成闭环，读者跟着人的轨迹走。调研型（如 006、008）靠"现象 → 拆解 → 多方观点 → 独立判断"形成闭环，读者跟着论证走。调研型对重复容忍度更低——同一个论点出现两次，读者会觉得你在凑字数而不是在推进。
- **​"承认对方合理性"这个策略在调研型里比叙事型更需要克制**。v1.0 在开头和第二节反复强调"Dario 的判断有事实基础""风险确实是真问题"，用意是避免写成阴谋论，但实际效果是论证节奏变慢。v1.1 把"承认合理性"集中压缩到第二节前半段，一次说完，不再反复。
- **社区反弹归纳需要和作者判断明确分层**。v1.0 的问题是，归纳完 HN 评论后立刻进入"Dario 可能是对的但这仍然危险"，读者分不清哪段是社区观点、哪段是作者观点。v1.1 用第三节纯做社区归纳（"他们反弹的是什么"），第四节纯做作者判断（"这意味着什么"）。
