来源：ECC continuous-learning-v2 在 Hermes 上的场景映射

ECC 的 instinct 学习模型（hook 自动观察 → 原子行为 → 置信度打分 → 进化成 skill），在 Hermes 上可映射为：

**已自动工作的场景：**
- 用户纠正操作方式（"不要用 cat，用 read_file"）→ 自动存 memory ✅
- 重复流程固化 → 手动 skill_manage(action='create') 存为 skill

**可手动做的事情：**
- 周末 session_search(query="completed OR corrected") → 发现重复模式 → 存 skill
- 跨项目模式晋升（2+ 项目都出现同一偏好 → 晋升到 shared-skills）

**差异：**
- ECC：全自动 hook 驱动，但有噪声（249 skill 中不少 low-confidence）
- Hermes：半自动，每次修正都有 real signal。更适合对质量有要求的场景
