## 2026-05-24 22:24

来源：反思 / repo PR #14、#15 合并后

### 核心理念

**公开运营系统，而不是公开运营结果。**

大多数自媒体账号只展示"结果"（一篇爆文、一个数字），偶尔展示"方法"（如果…怎么做…）。几乎没有人展示"系统本身"——那个每天在自动运转的、由 repo + agent + workflow 构成的产物线。

把 china-ai-frontline 这个 repo 当成一个**开源运营系统**来展示：
- 不是教你怎么做自媒体
- 是打开我的运营系统让你看内部结构
- 每一次 PR、每一条 issue、每一份 agent 日志，都是内容

### 内容形态

这条支线的内容不是"方法论分享"，而是**产品演示**：

```
posts/x.md/"#post-2026-05-24-001"
├── 标题：我把自媒体当 GitHub repo 来运营
├── 形式：X Thread（6条）
├── 证据链：
│   ├── PR #14 → 一条 agent 提交的修改
│   ├── inbox/ → 想法从碎片到结构化的路径
│   └── GOVERNANCE.md → express lane 的设计哲学
└── 核心论点：不是教你怎么做，是给你看我在做
```

### 爆点判断

这个做法的独特之处在于**层次感**：

| 层 | 内容 | 对外展示 |
|----|------|---------|
| 1 | 告诉别人你在用AI做自媒体 | 烂大街，没人在乎 |
| 2 | 告诉别人你的具体工作流 | 有一点价值，但本质还是方法论 |
| 3 | **把工作流本身变成产品** | 没人这样做——你的 repo 就是你的 CMS |

第三层才是爆点。不是"我用 AI 做自媒体"，而是"**这是我的 repo，这是我的 workflow，这是 agent 今天给我写的 PR，这是那个 PR 背后的 system prompt**"。

### 内容素材（已存在的）

1. **inbox → posts → topics 的三层升级制** — 碎片想法到结构化内容的完整 pipeline
2. **GOVERNANCE.md express lane** — 为什么只放开 inbox 追加和反馈回填？这是刻意设计的约束
3. **social-content-loop.md** — agent 每天怎么自动处理你的 inbox
4. **browse.sh → bb-sites 翻译项目** — 0 token 获得 12306 查票 API 的真实工程案例
5. **PR #14 + #15 合并后的反思** — 这个想法本身是怎么从 inbox 升级成 posts 的

### 目标受众

| 人群 | 为什么会在乎 |
|------|------------|
| AI builder / coding agent 用户 | 看一个真实的 agent 驱动工作流长什么样 |
| 独立创作者 | 一种全新的内容生产模式（不靠灵感靠系统） |
| 想用 AI 但不写代码的人 | 看一个非技术人员怎么用 agent 放大产出 |
| 技术自媒体 | 少见的素材——技术和自媒体的交叉点 |

### 验证指标

这条支线的成功不是看点赞数，而是看：
- 有人 PR 你的 repo → 他理解了你在做什么
- 有人 fork 你的结构 → 他真的用了
- 有人讨论「repo-as-CMS 这个概念」→ 你定义了新赛道

- 我们的浏览器核心（WSL chromium 有头模式、360ChromeX）是本地运行的
- 需要搞一个适配层：browse.sh 的 SDK → 我们的 CDP 接口

### 🔥 翻译结果：11 个适配器完成（2026-05-25）

基于 browse.sh 的元数据，翻译了 11 个中国优先的站点适配器到 bb-sites 仓库。总代码 ~2,936 行。

**翻译策略**：browse.sh 定义了每个站点的执行方法（browser/api/fetch/hybrid），我们采用 hybrid 策略——优先用 API/fetch 路径（0 token），降级到浏览器 DOM 提取。

#### 关键对比：browse.sh 方法 vs 我们的实现

| browse.sh 方法 | 我们的策略 |
|---------------|-----------|
| browser (101 个) | API/fetch 优先 → 失败走 browser |
| hybrid (41 个) | API 优先 → browser fallback |
| 原绑定 Browserbase 云端 | 改用本地 CDP（WSLg/360ChromeX） |
