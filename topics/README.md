# topics/ — 选题卡片目录

选题卡片按内容支柱（pillar）组织，与 `docs/content-pillars.md` 中的 5 个支柱一一对应。每个 pillar 目录下有对应的 `README.md` 描述该支柱的启用状态和选题清单。

## 支柱总览

| 支柱 | 定位 | 状态 | 选题数 | 内容簇覆盖 | 下一篇优先级 |
|---|---|---|---|---|---|
| [一](pillar-1/) | 路演现场一手情报 | 🔒 M3 启用 | 0 | — | — |
| [二](pillar-2/) | 模型与产品横评 + 生态地图 | 🟡 冷启动延展 | 1(+2 跨目录) | #002 已发 / #003 待写 | 中(#003) |
| [三](pillar-3/) | 连接节点(访谈/判断/know-how) | 🔒 M3 启用 | 1 | #004 待写(内容簇伏笔) | 中(#004) |
| [四](pillar-4/) | 中美双边视角 | 🟢 **冷启动主力** | 4(1已发,3 暂归档) | #001 已发 | **高**(005 内容簇收尾) |
| [五](pillar-5/) | 可操作工具箱 | 🟢 **冷启动钩子** | 1 | #002 交叉参与 | 中(004 pipeline) |

> 选题数包含卡片的实际编号文件。跨目录选题(pillar-4 下的 002/003/005 分别归属支柱二和元层)计入所在目录的选题数,在 README 中标注了暂归档状态和迁移计划。内容簇(前 5 篇)覆盖指 cold-start-plan 中的内容簇分配。

## 编号规则

选题编号为**全局流水号**,跨 pillar 不重复。

- `pillar-4/004-*` 不存在,因 004 位于 `pillar-5/`
- 000 为模板模板(`_template.md`),不占用正式编号

## 选题卡片结构

每张选题卡片统一使用 `_template.md` 中的 YAML frontmatter + Markdown 正文格式。
