# 不是被吃掉，是分层共存：平台型 agent 与工具型 agent 的终局

## 一句话价值主张

平台型 agent 做广度（80% 用户的浅层需求），工具型 agent 做深度（20% 用户的个性化 workflow）——两者分层共存，不是谁吃掉谁。

## 受众钩子

- **谁会转发**：AI agent builder、关注 AI 产品 PMF 的从业者、OpenClaw/Hermes/Reasonix 用户
- **谁会收藏**：在犹豫「要不要学 Coze」或「要不要搭本地 agent」的个人开发者
- **谁会觉得「我以前不知道这个角度」**：大多数人看到的叙事是「大厂做平台会赢」，不知道还有「分层共存」这个框架

## 核心论点 / 内容骨架

1. **Coze 3.0 真正在卖什么**：不是模型参数，是「打开就能替我做一部分工作」。模型是基础设施，skill 是卖点。
2. **平台经济的必然性**：字节有豆包+飞书+Coze+抖音全栈，行业 know-how 库的网络效应，云端算力成本优势——平台做广度是自然选择。
3. **但个人 agent 有 5 个不可替代性**：隐私合规、延迟离线、个性化深度（6 个月的 workflow 训练）、跨平台资产、创作主权。
4. **分层共存模型**：平台 = 浅层广度（80% 用户），工具型 agent = 深度个性（20% 用户）。两者不竞争，可合作（MCP 桥接 + 技能蒸馏）。
5. **三条内容线的收敛**：repo 运营（我的 workflwo 长在自己身上）、API 不平等（平台不给就自己长）、三阶段（第二阶段造什么车）→ 都指向同一个判断。
6. **终局判断**：不是被吃掉，是分化。20% 用户市场够大（Linear/Notion/Figma 已验证），工具型 agent 的关键不是拼规模，是守住「个人资产沉淀」这一定位。

- 避免「平台 vs 个人」二元对立叙事——框架核心是「分层共存」不是「谁好谁坏」
- 避免泛泛的「AI 革命」叙事，用具体的 Coze skill store 例子和三条内容线的真实案例
- 注意：字节如果下半年发布个人 agent 产品，文章判断要被重新审视——需要标注"截至 2026-06 的判断"
- 不贬低 Coze——承认平台的价值，再谈个人的不可替代性，这样更有说服力
