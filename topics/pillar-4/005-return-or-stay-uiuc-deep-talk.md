# 回国做 AI 还是留在海外做华人市场:和 5 个 30 岁前后的 UIUC 校友的深聊

## 一句话价值主张

把 #001 提的"7 个人 7 个赌注"里那些**没回国但也没躺平**的人,单拎出来讲一讲——"留在海外做华人市场"是一个被忽视的第三选项,这次把它讲清楚。

## 受众钩子

- **谁会转发**:正在思考"我可以不回国,但能不能不只是打工"的原型 B(可能比 #001 转发率更高,因为命中海外华人现实)
- **谁会收藏**:想做副业 / 创业的海外华人工程师
- **谁会觉得"我以前不知道这个角度"**:把"回 vs 留"这个二元选择,拆成"回国 / 海外华人市场 / 全球市场"三元选择

## 核心论点 / 内容骨架

1. **开篇钩子**:5 个 30 岁前后、都没回国、但都没只在大厂打工的 UIUC 校友
2. **5 个"留下来做点什么"的样本**(可化名):
   - 例:在硅谷做面向北美华人的 AI 工具
   - 例:在伦敦做中英双语的 AI agent
   - 例:在新加坡做东南亚华人圈层的产品
   - 例:留在大厂内部转岗到面向中国市场的部门
   - 例:做小公司技术合伙人,客户都是国内出海公司
3. **他们的共同观察**:
   - "海外华人市场"是不是一个真实的市场?有多大?
   - 用什么模型 / 工具栈?(钩子回到支柱二支柱五)
   - 痛点是什么?(支付 / 合规 / 文化 / 用户认知)
4. **他们的不安**:
   - 文化认同与归属
   - 跟不上国内速度的恐惧
   - 家人 / 签证 / 婚恋的现实
5. **这条路适合什么样的人?**(给读者一面镜子,不下结论)

## 关键素材 / 信源

- [ ] 5 个 UIUC 校友访谈(每人 30-60 分钟,可化名)
- [ ] 各自具体的项目 / 公司锚点(脱敏后描述方向即可)
- [ ] 一些数据锚定(海外华人市场规模、北美华人 AI 工具公司清单)

## 风险与避坑

- **不要变成"海外华人创业鸡汤"** → 必须有"哪里不舒服 / 哪里失败"的部分
- **化名一定彻底** → 同 #001
- **避免和 #001 重复** → #001 是"回国的人在赌什么",#005 是"没回国的人在做什么",视角必须互补不重合
- **结尾不下结论** → 这一篇是月度收尾,不是判决书
