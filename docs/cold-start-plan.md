## 核心判断:从 0 不是从负

公众号 6400 关注、断更 12 个月 → **不是冷启动,是负启动**。
断更杀伤的具体机制:推送降权 / 信息流位次后置 /「常读」标记清空 / 微信自动折叠到「不常读」二级菜单。账号在后台还在,**在用户视野里基本消失**。

**真实资产不是 6400,是其中 50–150 个 UIUC 圈层 KOC**——他们决定每篇新文章的初始水位。

→ 第一目标:**重建信号**(让平台和老粉重新识别"在认真做事,且做的是新东西")
→ 不是涨粉。

## 三条战术原则

1. **不发"复更说明"** —— 用第一篇炸裂内容当复更动作本身。已用 001 完成。
2. **老粉回魂率 > 新粉入场率** —— UIUC 节点少、密度高、二级传播路径短,效率高公域算法一个数量级。
3. **前 5 篇必须是主题一致、调性一致、质量陡升的内容簇** —— 算法机制:4–8 篇相似度+互动率组合判定。

## 频率与库存纪律

**发布频率:周更**(每周 1 篇,不双周)

**库存机制**(与战略第零条「作者可持续性」绑定):
- 内容簇收尾期间(接下来 3–4 周)冲刺写 003 / 004 / 005 + 同步开始建库存
- **目标:8 篇库存缓冲**(永远比 deadline 多 ≈ 2 个月存货)
- 库存的作用:抵御短期波动(出差 / 生病 / 出活儿不顺 / 工作忙)
- **库存数学约束**:库存只能抵御 8 周的产能波动。长期产能 ≥ 发布需求是前提,否则库存只是延缓崩盘

**单篇工作量管理**(解决长期产能问题):

| 机制 | 月度落地节奏 |
|---|---|
| 长短文混合 | 每月 2 篇深度长文(6000–8000 字)+ 2 篇短篇(2500–3500 字:产业速记 / 工具卡 / 读者问答整理)|
| 选题预制化 | 长选题拆 2–3 篇连载,避免每周都从零开题 |
| AI 辅助前置 | Claude / GPT 做素材抓取、信息整理、初稿草拟,作者保留判断、视角、结构、润色 |
| 复用社群素材 | 群讨论 / 私信 / 访谈片段加工成「连接笔记」类短篇 |

## 验收指标(看趋势,不看绝对值,前 3 个月不看涨粉)

- **老粉回流**:阅读 / 关注比是否恢复到断更前水准(特别是 001 / 002 已唤醒过的)
- **二级传播**:UIUC 校友群 / 海外华人创业群 / 国内 AI 团队群是否出现自发转发
- **完读率**:算法重新打标的关键变量
- **重复读者**:连续打开 ≥ 3 篇的人数
- **双边反馈**:国内团队 + 海外创业者的私信 / 留言 / 约聊
- **留存**:工具型内容(支柱五)收藏 / 阅读比是否显著高于其他篇
- **调性一致性**:任意两篇放在一起,读者能不能感觉是同一个号
