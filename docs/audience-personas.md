# 受众画像

## 辐射锚点

**UIUC(伊利诺伊大学香槟分校)校友网络,毕业年份 2017–2026**。
这是冷启动期内容传播的初始信任网络,不是天花板。

## 三个原型(冷启动期权重)

### 原型 A:在读研究生(权重 = 25%)

- **谁**:CS/ECE/商科研究生,对 AI 创业感兴趣
- **日常信息源**:X、Hacker News、a16z 博客;对 OpenAI / Anthropic / Mistral 如数家珍
- **对中国 AI 的认知**:豆包、Kimi、智谱、MiniMax、阶跃、月之暗面、DeepSeek、通义、文心——既好奇又模糊
- **真痛点**:
  - 看不到一手现场(路演、发布会、闭门会)的氛围和细节
  - 不知道国内创始人真实在想什么、投资人真实在问什么
  - 担心毕业回国 or 在海外做华人市场时,错过窗口期

### 原型 B:海外工作 3–8 年的工程师 / PM(权重 = 60%,**冷启动主力受众**)

- **谁**:UIUC 2017–2022 届,目前在 FAANG / 硅谷初创 / 伦敦 / 新加坡
- **当下决策窗口**:
  - 要不要回国加入一家 AI 公司?
  - 要不要在海外做一个"中美双边"的 AI 产品?
- **真痛点**:需要的不是新闻,是**判断依据**——估值、团队、技术路线、政策、人才流动方向
- **情绪**:对中国 AI 是复杂情绪——既有"超越美国了"的兴奋,也有"会不会被卡脖子"的焦虑
- **转发动机**:身份认同 + 同辈决策参考
- **为什么是冷启动主力**:正好卡在临界决策点,内容直击决策痛点,转发率最高

### 原型 C:海外独立开发者 / 小型创业者(权重 = 15%)

- **谁**:想用国内便宜又强的 API (DeepSeek / 通义 / Kimi) 做产品
- **真痛点**:合规、支付、网络访问、模型选型搞得很头大
- **要的东西**:可操作的工程级情报
- **冷启动期角色**:支柱五"工具型钩子"内容的目标用户

## 内容判断准则

每篇选题问自己:
1. 原型 B 看完后,**会不会转发给同事 / 师兄?**(转发率)
2. 原型 C 看完后,**会不会收藏起来下次用?**(收藏率)
3. 原型 A 看完后,**会不会觉得"我以前不知道这个角度"?**(认知增量)

至少要命中其中两条。
