# 渠道矩阵

冷启动期发布渠道、节奏、改写策略。

## 渠道角色

| 渠道 | 角色 | 主要受众 | 改写策略 |
|---|---|---|---|
| 公众号 | **主战场** / 复更阵地 | 老粉 + 国内圈层(创始人、投资人会看到) | 完整版,2500-4500 字 |
| X (Twitter) | 海外华人 + 英文工程师圈 | 原型 A、B、C | 中文长推 + 英文摘要,数据可视化截图 |
| Substack | 海外深度读者 / 英文圈 | 原型 A、B(英文圈) | 英文重写,不要直译,可独立扩展系列 |
| 小红书 | 测试性投放 | 原型 A 留学生 / 原型 B 女性比例较高内容 | 卡片化 / 标题口语化,慎用于身份焦虑话题 |
| 即刻 / 知乎 | 视情况搬运 | 国内圈层 | 摘要 + 公众号链接 |

## 公众号 → 其他渠道的"压缩比"

- 公众号一篇 3000 字 → X 长推 = 5-10 条 → Substack 英文 ≈ 1500 词 → 小红书 = 1-2 张图卡 + 200 字

## 发布顺序

- **公众号先发,2-6 小时后同步 X 和 Substack** —— 给老粉优先权
- **小红书延后到次日或第三日** —— 避免互相吃流量
- 工具型内容(#004)发完后,**第二周再发一次"补丁更新"短推** —— 拉长尾流量

## 关注转化钩子(每篇必备)

- 文末固定模块:**"如果你也是海外做 AI 的华人,关注一下这个号,我每周聊一件具体的事"**
- 工具型 / 清单型内容:**附带 Notion / 飞书可访问的活文档**,公众号关注后回复关键词获取

## 跨平台 ID 一致性

- 公众号、X、Substack、小红书使用同一品牌名("中国 AI 前线" / "China AI Frontline")
- 头像、简介、第一句自我介绍保持一致
- Substack URL、X handle、公众号原始 ID 互相在 bio 里挂出
