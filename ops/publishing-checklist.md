# 发布前自查清单

每一篇发布前过一遍。**没全部 ✅ 不发**。

## 一、定位 / 受众

- [ ] 这篇命中了 `docs/audience-personas.md` 里的至少一个原型(主原型 B,辅原型 A/C)
- [ ] 我能用一句话讲清楚这篇的"价值主张"是什么
- [ ] 能回答:**原型 B 看完会不会转发?** **原型 C 看完会不会收藏?**

## 二、调性

- [ ] 没有"翻译型"内容(不是把英文 / 中文新闻搬运)
- [ ] 没有只报喜或只报忧的倾向 —— **冷静、数据驱动、有立场但不站队**
- [ ] 没有"加班 / 内卷 / 爱国"等情绪牌
- [ ] 有"哪里不行"的部分(不是软文)

## 三、UIUC 锚点纪律

- [ ] 这篇是否需要 UIUC 锚点?(对照 `docs/cold-start-plan.md`)
- [ ] 如果用了 UIUC 锚点,是否自然且仅出现 1-2 处?
- [ ] 全月内容里,UIUC 锚点频率是否 ≤ 20%?

## 四、可信度 / 合规

- [ ] 所有数字 / 引用都能溯源
- [ ] 涉及具体公司 / 人物,有没有可能反向定位?化名是否彻底?
- [ ] 如果涉及合规话题,有没有踩政策线?
- [ ] 模型版本 / 价格 / 政策类信息,**发文前 24 小时内再核对一次**

## 五、形式

- [ ] 公众号版本字数 / 排版 / 配图 / 表格齐备
- [ ] X / Substack 同步版本是否已准备(精简 ≠ 复制粘贴)
- [ ] 标题至少打磨过 3 版
- [ ] 第一段(钩子段)能否在 3 秒内抓住原型 B?

## 六、留存设计

- [ ] 文末是否给读者下一步动作?(关注 / 加群 / 跳到附件 / Notion 文档)
- [ ] 工具型内容是否有可收藏的"实体"(表格 / 清单 / Notion / 飞书)?

## 七、复盘准备

- [ ] 已在选题卡片预留"发布后记录"区
- [ ] 设好 7 天 / 30 天复盘提醒
