# data/ — 结构化数据目录

存放每篇文章相关的结构化数据文件（如 Excel 明细、CSV、JSON 等），与 `topics/` 下选题卡片一一对应。

## 目录结构

```
data/
├── README.md
├── 001/             ← topics/ 下的 001 号选题
│   ├── README.md
│   ├── 20260513_数据明细（...）.xls
│   └── ...
├── 002/             ← 002 号选题
│   └── ...
└── ...
```

## 命名规则

1. **数据文件命名：日期放在文件名最前面**
   - 格式：`YYYYMMDD_描述（文章标题简写）.扩展名`
   - 例：`20260513_数据明细（毕业9年后，我认识的4个UIUC....xls`
   - 日期来源：数据明细内容中的日期列
   - 日期若无明确来源，使用数据发布日期

2. **子目录**：`data/NNN/` 对应 `topics/` 下的 NNN 号选题

## 可变性原则

数据文件一旦提交即视为基线版本，不直接修改。如需更新数据，以新日期命名追加新文件，旧文件保留作为历史记录。
