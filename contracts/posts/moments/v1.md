# Post Contract — Moments（朋友圈）v1

> extends: contracts/posts/v1-common.md
> 平台：微信朋友圈
> 本合同只定义 Moments 平台特定维度，硬性禁区、Draft 字段、Review Log 格式均继承 v1-common。

## 1. 平台定位（写给 agent 看的）

朋友圈生态特征：
- 受众是**熟人 + 半熟人混合圈层**，不是公开 audience
- 算法权重极弱，谁看到主要靠社交关系
- 用户消费动机是"看朋友最近怎么样"，不是"学知识"
- 容忍碎片、容忍情绪、奖励真实、惩罚营业感
- 重大反差：在 X / 小红书会扣分的"轻量、不完整"，在朋友圈反而是优点
- 一旦像广告 / 像营销 / 像复制粘贴，立刻在熟人面前掉信任

**因此本平台的内容必须做到：让看的人觉得"这是他本人写的"，而不是"这是他在运营人设"。​**

## 2. 平台特定写作规则

### 必须满足
1. **像在跟朋友说话**：语气自然，不端着
2. **保留模糊与未完成感**：可以不下结论，可以只是观察
3. **配图与文字共同承担表达**：文字不必把图说尽
4. **轻量优先**：能 1 句说完不说 2 句
5. **保留人的体感**：天气、心情、地点、状态都是合法素材

### 明确禁止
1. **公开演讲腔**：像在做发布、做总结、做汇报
2. **小红书化笔记**：分点列表、emoji 装饰、"建议收藏"
3. **X 化锐评**：朋友圈不是辩论场，过强的攻击性会破坏熟人关系
4. **明显营业**：连续多条同主题、明显在"立人设"
5. **AI 客服腔**：对仗工整、四字结构、空泛升华

## 3. 平台特定评分维度（60 分）

### 3.1 真实感与人味（0-20）

朋友圈最贵的就是"像本人"，所以这个维度权重最高。

| 分数 | 判据 |
|---|---|
| 17-20 | 一看就是本人随手写的，有体感、有当下感 |
| 13-16 | 有人味但稍微"修过" |
| 9-12 | 中性，看不出是不是 AI |
| 5-8 | 有明显修饰痕迹，像在"发"而不是"说" |
| 0-4 | 完全 AI 腔 / 营业腔 |

**红线**（任一触发 ≤4 分）：
- 出现"今天想和大家分享 / 借此机会"这类公开演讲开头
- 通篇没有任何当下场景（时间 / 地点 / 状态）
- 用对仗工整的四字结构（"砥砺前行 / 行稳致远"）
- 像在"做内容"而不是"过日子"

**增分点**：
- 写到具体当下细节（"刚煮的咖啡苦了" / "地铁上"）：+3
- 自嘲 / 暴露小尴尬 / 暴露弱点：+3
- 不下结论，只描述：+2

### 3.2 轻量与节制（0-15）

朋友圈不是越长越好，越长越不像本人。

| 分数 | 判据 |
|---|---|
| 13-15 | 长度恰到好处，没有一句多余 |
| 10-12 | 略长但不冗 |
| 7-9 | 偏长，能砍 30% |
| 4-6 | 明显写作过度，像小作文 |
| 0-3 | 长篇大论，应该改投公众号 |

**长度参考**：
- **甜区**：30-150 字
- **可接受**：150-300 字
- **警戒线**：300 字以上需要主编特批
- **硬上限**：500 字（朋友圈折叠后阅读率断崖）

**扣分点**：
- 长度超过 300 字：-3
- 长度超过 500 字：-7
- 出现"展开说说"、"详细聊聊"这类公开化口吻：-5

### 3.3 关系适配（0-15）

朋友圈的读者是**多重身份混合**：同事、客户、家人、老同学、行业熟人。

| 分数 | 判据 |
|---|---|
| 13-15 | 多个身份的人看了都不会觉得不舒服 |
| 10-12 | 主要受众舒服，少数身份可能皱眉 |
| 7-9 | 一半受众觉得 OK，一半觉得突兀 |
| 4-6 | 明显只对某一群人友好 |
| 0-3 | 会让一半以上熟人感到尴尬或被冒犯 |

**扣分点**：
- 含明显行业黑话且未做翻译（家人看不懂）：-3
- 含可能让客户 / 老板尴尬的情绪表达：-5
- 含可能让家人担心的负面情绪未做处理：-5

**注意**：朋友圈是熟人空间，agent 不能假装这是公开舞台。

### 3.4 情绪健康度（0-10）

朋友圈不禁止负面情绪，但禁止"未消化的负面"。

| 分数 | 判据 |
|---|---|
| 9-10 | 情绪真实，但已被作者本人消化过 |
| 7-8 | 情绪有但克制，留有余地 |
| 5-6 | 情绪稍重，读者可能担心 |
| 3-4 | 情绪发泄，未做处理 |
| 0-2 | 攻击性 / 怨气 / 失控 |

**红线**（任一触发 ≤2 分）：
- 直接攻击具体可识别的人（哪怕没点名）
- 表达自伤倾向（即使是修辞）
- 持续多条同类负面情绪（情绪轰炸）

## 4. 配图规则

朋友圈是图文一体的平台。如果 draft 包含配图意图，额外检查：

1. **图必须真实**：不允许 AI 生成图冒充真实场景
2. **图文不能完全重复**：图说一遍，文字不必再说一遍
3. **不要 9 图凑数**：3-6 图甜区，9 图除非是真实组图

如果 agent 不能确定配图，需要在 draft 中显式标注 `image_intent: <描述>`，不能假装已配图。

## 5. 增分项（可叠加，最多 +5 不封顶）

朋友圈本身就反对"加分技巧"，所以增分项很克制：

- 一个具体的小细节（声音、味道、温度、动作）：+2
- 不发表观点，只如实描述：+2
- 自嘲一下：+2
- 一句话戛然而止，不解释：+3

## 6. 平台特定硬禁区（在 v1-common 之外追加）

任一触发，直接 rejected：

1. **明显营销 / 引流**：朋友圈是熟人空间，硬广直接掉信任
2. **未脱敏的他人信息**：包括对话截图、群聊内容、孩子正面照
3. **连续 3 条同主题**：会被熟人识别为"在运营"
4. **复制粘贴自其他平台**：朋友圈最忌"看出你是搬运的"
5. **明显 AI 腔**：在熟人面前 AI 腔比在公开平台更扣分

## 7. 合格朋友圈最小骨架

朋友圈不应该有"骨架"，但 agent 仍可参考：

[1 行场景或体感]
[1-2 行观察 / 动作 / 心情]
[（可选）1 句不下结论的余味]


或更短：
[1 句话 + 1 张图]

绝大多数朋友圈不需要超过 3 行。

## 8. 通过门槛（覆盖 v1-common §7）

朋友圈对真实感和节制的要求高于 X 和小红书：

- `total >= 80` 且 `真实感与人味 >= 15` 且 `轻量与节制 >= 11`：approved
- `total >= 80` 但 `真实感 < 15`：needs_revision（提示去 AI 腔）
- `total < 80` 或 `情绪健康度 <= 4`：回退重写

**特别规则**：
- 真实感 ≤ 8 的草稿一律不能发朋友圈，建议改投 X（短观点）或小红书（深度笔记）
- 长度超过 500 字的草稿一律 needs_revision，无论分数多高
- 朋友圈通过门槛 80（低于其他平台 5 分），因为朋友圈本来就鼓励"轻量"，过度打磨反而扣"真实感"

## 9. 与其他平台的内容路由建议

agent 在拿到一个原始想法时，可参考以下默认路由：

| 想法特征 | 默认平台 |
|---|---|
| 有方法 / 有清单 / 可复用 | 小红书 |
| 有观点 / 有判断 / 有刺 | X |
| 只是记录 / 没有结论 / 有当下感 | Moments |
| 三者都不像 | 留在 inbox，不强制升级 |
